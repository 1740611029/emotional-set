# Spec Delta

## MODIFIED Requirements

### Requirement: 二级板块详情弹窗

点击二级细分板块时，页面 MUST 在当前一级板块页面上打开该二级板块的详情弹窗，MUST NOT 用二级板块替换一级板块主详情或隐藏二级细分列表。二级细分板块列表每行 MUST 提供显式的"详情"入口按钮，保证用户无需知晓"点击整行"也能发现弹窗。弹窗 MUST 居中于视口显示（水平与垂直方向），且在内容高度变化与不同窗口尺寸下 MUST NOT 超出视口。弹窗 MUST 展示二级板块自身的独立状态、与父级状态的差异、有向强度、持续天数、数据日期及收盘走势图，并 MUST 支持 60 / 120 / 250 个交易日范围切换。

#### Scenario: 打开二级板块详情

- **WHEN** 用户点击二级细分板块列表中的某个板块行或该行的"详情"按钮
- **THEN** 页面 MUST 打开该板块的详情弹窗，背景中的一级板块主详情与二级列表 MUST 保持原选中状态

#### Scenario: 详情按钮与整行点击行为一致

- **WHEN** 用户点击某二级板块行的"详情"按钮
- **THEN** 打开的弹窗 MUST 与点击该行任意其他位置完全相同（同一板块、同一数据口径），且 MUST NOT 触发行的重复或冲突行为

#### Scenario: 弹窗居中于视口

- **WHEN** 二级板块详情弹窗处于打开状态
- **THEN** 弹窗 MUST 在视口中水平与垂直居中显示，MUST NOT 停在视口左上角或其他偏移位置

#### Scenario: 小窗口或高内容下不溢出视口

- **WHEN** 浏览器窗口较小，或弹窗内容高度超过窗口可用空间
- **THEN** 弹窗整体 MUST 仍位于视口内，内容区 MUST 可滚动查看超出部分，且弹窗 MUST 保持居中

#### Scenario: 弹窗使用二级板块自身数据

- **WHEN** 二级板块详情弹窗加载完成
- **THEN** 弹窗中的状态、强度、日期与历史序列 MUST 来自被点击的二级板块，MUST NOT 回退或替换为父级板块数据

#### Scenario: 关闭弹窗恢复浏览

- **WHEN** 用户通过关闭按钮或 Escape 键关闭弹窗
- **THEN** 页面 MUST 返回打开前的一级板块浏览上下文，且 MUST NOT 重新选择其他一级板块

#### Scenario: 弹窗历史加载中或失败

- **WHEN** 二级板块历史数据尚未返回或请求失败
- **THEN** 弹窗 MUST 显示对应加载或失败状态，MUST NOT 展示父级序列或编造的示例数值

#### Scenario: 弹窗内切换时间范围

- **WHEN** 用户在弹窗内切换 60 / 120 / 250 日范围
- **THEN** 走势图 MUST 按该二级板块自身的历史数据重绘，且 MUST NOT 关闭弹窗或刷新整页
