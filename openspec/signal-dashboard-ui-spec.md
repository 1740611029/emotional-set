# SignalHub 信号指标中心 —— UI 设计规范与前端需求规格

## 1. 项目背景

SignalHub 是一个面向量化交易者的信号指标可视化平台，采用**多因子评分 + 分层确认架构**。输入为 7 大宽基指数（沪深300、中证500、上证50、创业板指、科创50、深证100、中证1000）的日线行情（OHLCV），涉及均线系统、动量指标、布林带、量能指标、回撤/反弹指标等多层因子。

项目核心机制为**确认型信号**：候选信号经价格、动量、量能三层确认后才展示给用户。评价口径从候选日改为确认日，以提高胜率、避免提前发出信号导致回撤。

---

## 2. 设计目标

- **风格定位**：清爽干净、清新淡色，非暗黑、非纯白
- **视觉感受**：专业可信、数据清晰、操作流畅
- **核心用户**：量化交易者、策略研究员
- **响应式**：优先桌面端（1920×1080 为主），适配 1440px 及以上

## 7. 页面清单

### 7.1 指标总览（Dashboard）

**功能**：展示全局信号统计、最新信号列表、指数概览

**元素**：
- 4 个 Summary Cards：今日确认信号、待确认候选、平均胜率、活跃指数
- 最新信号状态表格（时间、指数、指标、信号类型、状态、确认层数）
- 指数信号分布图（环形图占位）
- 近30日信号趋势图（折线图占位）

### 7.2 指标详情页（每个指标一个页面）

**当前指标列表**：
1. 均线交叉（MA Crossover）
2. 动量指标（Momentum）
3. 布林带（Bollinger Bands）
4. 量能指标（Volume）
5. 回撤/反弹（Drawdown/Rebound）
6. 综合评分（Composite Score）

**页面结构**：
- 指标标题区：图标 + 名称 + 描述 + 今日信号统计
- 主内容区（左 2/3）：信号历史走势图 + 时间周期切换（7日/30日/90日）
- 侧边栏（右 1/3）：指标参数面板 + 统计概览（胜率、盈亏比、信号数、最大回撤）
- 底部：确认机制日志（价格确认 → 动量确认 → 量能确认）

### 7.3 宽基指数（Indices）

**功能**：7 大指数实时监控卡片

**卡片内容**：
- 指数名称 + 当前趋势标签（多头/空头/震荡）
- 当前点位
- 涨跌幅（绿色/红色/灰色）
- 信号数量 + 胜率

## 8. 交互规范

### 8.1 页面切换

- 左侧导航点击切换页面
- 页面切换动画：opacity 0.3s ease
- 内容区 fadeIn：opacity + translateY(8px) → opacity 1 + translateY(0)，0.4s ease-out

### 8.2 卡片交互

- Hover：背景变亮、阴影加深、上移 2px
- 点击：无特殊反馈（当前为展示型）

### 8.3 表格交互

- 行 hover：背景变为 Slate 50
- 排序：表头点击排序（后续实现）
- 筛选：顶部搜索框实时筛选（后续实现）

## 9. 扩展性设计

### 9.1 新增指标流程

1. 在侧边栏导航增加新的 `<a>` 项
2. 复制指标详情页模板，修改 `id` 和标题
3. 在 `titles` 映射中加入新指标名称
4. 替换图表占位为真实图表组件

### 9.2 新增指数流程

1. 在宽基指数页面增加新的卡片
2. 卡片数据通过 API 动态获取

## 11. 非目标（Non-Goals）

- 不支持移动端优先（桌面端优先）
- 不实现实时推送（轮询或 SSE 即可）
- 不实现用户登录/权限管理（后续迭代）
- 不实现信号自动交易（纯展示与分析）
