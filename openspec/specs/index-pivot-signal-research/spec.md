# index-pivot-signal-research Specification

## Purpose
定义"指数点位拐点"信号算法的离线调研与对照决策契约：以事后标注的真实价格拐点为统一基准，评估候选拐点算法与辅助因子组合是否比现行六因子情绪共振算法更准确地定位指数顶底拐点，并输出可复现、可追溯、三态化的采纳结论，供用户决定是否更换生产算法。

## Requirements

### Requirement: 真实拐点基准集构建

系统 MUST 在生产指数历史（7 个指数）上构建"真实拐点基准集"（ground truth）：每个拐点记录指数代码、日期、类型（`top` / `bottom`）与价格。拐点标注规则 MUST 为事后确认制——某日仅在其后价格反向运动达到幅度阈值且持续满足最小间隔时才被标注为拐点；幅度与间隔阈值 MUST 在训练段内选定并冻结，验证段 MUST NOT 再调整。基准集 MUST 附带输入数据哈希，输入行情变化时 MUST 可识别并重建。

#### Scenario: 拐点标注事后确认
- **WHEN** 某交易日之后价格未发生达到冻结阈值的反向运动
- **THEN** 该日 MUST NOT 被标注为拐点

#### Scenario: 阈值冻结不随验证结果漂移
- **WHEN** 验证段对照结果不理想
- **THEN** 基准集拐点标注阈值 MUST 保持训练段冻结值，MUST NOT 用验证段数据重选阈值后再报告为验证结果

#### Scenario: 逐指数可追溯
- **WHEN** 输出基准集产物
- **THEN** 每个拐点的日期、类型、价格 MUST 可与原始日线逐条核对，且产物 MUST 附指数代码、区间与输入哈希

### Requirement: 候选拐点算法登记与因果性

每个进入对照的候选拐点算法 MUST 登记：名称、计算定义、参数取值范围、所用数据依赖、无未来函数自检结论。候选算法 MUST 覆盖价格结构类主干（如 ZigZag 高低点破位、滚动窗口高低点突破、分形/笔段类规则），参数只在训练段选取。候选算法在 T 日输出的信号 MUST 只依赖 T 日及之前的数据：将 T 日之后的数据全部置空或打乱，T 日及之前的信号集合 MUST 完全不变。

#### Scenario: 登记缺项不得进入回测
- **WHEN** 某候选算法未登记完整（缺定义、参数范围、数据依赖或自检结论任一项）
- **THEN** 该算法 MUST NOT 进入对照回测

#### Scenario: 未来数据不影响历史信号
- **WHEN** 将某候选算法输入行情在 T 日之后的数据全部置空或打乱
- **THEN** 该算法在 T 日及之前生成的信号日期、类型、数量 MUST 完全不变

### Requirement: 辅助因子只加分不否决

调研 MUST 支持把资金面、情绪面、技术面、外围环境等因子作为辅助项，对拐点候选加分与分级；辅助因子 MUST NOT 作为信号产生的必要条件，MUST NOT 否决价格结构已成立的拐点候选。每个辅助因子 MUST 仅使用信号日当日已可得的数据，并登记出处；历史不足 5 年或存在事后修订的因子 MUST 按既得因子可得性分级（P0/P1/P2）处理，不得评为可直接采纳。

#### Scenario: 辅助因子不参与信号生成
- **WHEN** 某拐点候选价格结构条件成立但全部辅助因子得分为零
- **THEN** 该候选 MUST 仍可成为信号，辅助得分 MUST 只影响等级标注

#### Scenario: 外围数据当日可得性
- **WHEN** 某外围环境因子（如隔夜美股、汇率、商品）在信号日 T 的数据尚未发布
- **THEN** 该因子在 T 日取值 MUST 视为缺失，MUST NOT 使用 T 日之后补齐的数值

#### Scenario: 历史不足降级
- **WHEN** 某辅助因子可用历史少于 5 年，或其统计口径存在事后修订
- **THEN** 该因子 MUST 被标为 P1 或 P2，且 MUST NOT 作为"更换生产算法"结论的主要增益来源

### Requirement: 拐点口径评价协议

候选算法的准确率 MUST 以"信号是否落在真实拐点附近"为口径度量，MUST 同时输出三类指标：（a）捕捉率——基准集拐点在 ±M 个交易日窗口内被信号覆盖的比例；（b）滞后分布——信号确认日相对拐点日的天数分布（含中位数与 90 分位）；（c）点位偏差——信号价格与拐点价格的相对偏差分布。主达标口径 MUST 为：信号确认后 ≤5 个交易日内落在真实拐点 ±N 日范围内；N 与 M MUST 在训练段确定并冻结。统计 MUST 分训练段与验证段分别输出，两段 MUST NOT 重叠且 MUST 设置不少于评价最长前瞻窗口的隔离期；每段结果 MUST 附样本量、统计区间与 Wilson 95% 区间，已判定样本少于 30 MUST 标注小样本。

#### Scenario: 主指标口径固定
- **WHEN** 报告某候选算法的准确率
- **THEN** MUST 按"确认后 ≤5 个交易日内落在真实拐点 ±N 日"的冻结口径计算，并给出 N、M 的取值与确定区间

#### Scenario: 调参与验证不得同段
- **WHEN** 某候选算法的参数在训练段选取
- **THEN** 其准确率 MUST 只在验证段报告；MUST NOT 用同一段数据既调参数又算准确率

#### Scenario: 小样本结论受限
- **WHEN** 某指数或某段区间的已判定样本少于 30
- **THEN** 该结果 MUST 标注"样本量较小，仅供参考"并如实给出样本量、统计区间与 Wilson 95% 区间

### Requirement: 新旧算法对照报告

对照 MUST 在同一拐点基准集、同一区间划分、同一指标口径下，将每个候选算法与现行生产算法 `index-swing6-v2.0` 并列输出结果。报告 MUST 包含全部参与候选（含被淘汰者）及其淘汰原因，MUST NOT 只报告最优候选。现行算法 MUST 以"信号日视为确认日"的既有语义参与对照，MUST NOT 为现行算法放宽口径。

#### Scenario: 全候选并列
- **WHEN** 输出对照报告
- **THEN** 报告 MUST 逐候选列出捕捉率、滞后中位数、点位偏差中位数与主指标达标率，并附样本量与统计区间

#### Scenario: 现行算法同基准对照
- **WHEN** 计算现行算法的对照指标
- **THEN** 现行算法 MUST 使用与候选算法相同的拐点基准集与冻结口径，指标差异 MUST 可逐项复算

### Requirement: 三态决策结论与生产零改动

调研 MUST 输出结构化为三态的决策结论：`更换建议`（新候选算法各主指标在验证段均不劣于现行算法且达标口径成立）、`观察`（结果不充分或小样本）、`保留现行`（候选算法不优于现行）；结论 MUST 附支撑数据，最终是否更换由用户决定，调研 MUST NOT 自行更换生产算法。整个调研流程 MUST NOT 改变生产信号任何输出：运行前后 `data/index-signals.json` 等生产产物 MUST 逐字节一致；调研产物 MUST 落盘于独立研究目录并附独立 manifest，删除调研产物后生产构建 MUST 不受影响。

#### Scenario: 调研不污染生产
- **WHEN** 运行拐点调研全流程
- **THEN** 生产信号文件的修改时间与内容 MUST 保持不变，调研产物 MUST 全部位于研究目录

#### Scenario: 结论必须三态之一
- **WHEN** 某候选算法完成对照
- **THEN** 报告 MUST 给出 `更换建议` / `观察` / `保留现行` 之一的明确结论与理由，MUST NOT 留空或含糊

#### Scenario: 采纳权在用户
- **WHEN** 调研结论为 `更换建议`
- **THEN** 生产算法 MUST 保持现行版本不变，直至用户另行发起更换生产算法的变更
