# live-data-ui Specification

## Purpose
定义前端的统一数据层与页面接入契约，确保所有现有页面与后续新增页面都从同一真实数据源取数、按 30 秒节奏刷新，并能清楚区分盘中临时态、收盘正式态与数据陈旧状态。

## Requirements

### Requirement: 单一数据源

所有页面 MUST 通过统一数据层获取行情与信号数据，MUST NOT 在页面或组件内硬编码指数点位、涨跌幅、胜率、信号条数等业务数值。新增页面 MUST 复用同一数据层，不得自行引入第二套数据来源。

#### Scenario: 页面无硬编码业务数值
- **WHEN** 审查任一页面的渲染逻辑
- **THEN** 页面 MUST 只消费数据层提供的类型化数据，MUST NOT 出现写死的点位、涨跌幅、胜率或信号数量

#### Scenario: 新增页面复用数据层
- **WHEN** 开发者新增一个展示指数或信号的页面
- **THEN** 该页面 MUST 从同一数据层取数，且无需新增请求逻辑即可获得刷新能力

### Requirement: 30 秒轮询与可见性控制

前端 MUST 默认每 30 秒重新获取一次快照；当页面处于后台或不可见时 MUST 暂停轮询，恢复可见时 MUST 立即刷新一次。用户 MUST 能手动触发刷新，并看到最近一次成功更新时间。

#### Scenario: 默认轮询间隔
- **WHEN** 页面可见且无用户操作
- **THEN** 数据 MUST 以 30 秒为周期自动更新

#### Scenario: 后台暂停
- **WHEN** 页面切换到后台
- **THEN** 轮询 MUST 暂停，恢复可见后 MUST 立即发起一次刷新

#### Scenario: 手动刷新
- **WHEN** 用户点击刷新控件
- **THEN** 前端 MUST 立即请求快照，并在完成后更新"最近更新时间"

### Requirement: 运行模式与时点标识

界面 MUST 明确展示当前数据的所属交易日（`as_of`）与运行模式：盘中临时态与收盘正式态 MUST 在视觉上可区分。盘中数据 MUST 带有"盘中临时"标识，且相关信号 MUST 标注为未确认。

#### Scenario: 盘中态可识别
- **WHEN** 快照 `mode` 为 `live`
- **THEN** 顶栏 MUST 显示盘中标识与当前时点，盘中信号 MUST 显示"盘中临时"标注

#### Scenario: 收盘态可识别
- **WHEN** 快照 `mode` 为 `close`
- **THEN** 顶栏 MUST 显示收盘标识与 `as_of` 交易日，且 MUST NOT 显示盘中临时标注

### Requirement: 加载、失败与陈旧降级

首次加载时 MUST 显示骨架或加载态；请求失败时 MUST 保留上一次成功数据并提示失败原因，MUST NOT 清空页面或显示占位假数据；数据陈旧时 MUST 显示陈旧提示与最近成功时间。

#### Scenario: 请求失败保留旧数据
- **WHEN** 快照请求失败且存在上一次成功数据
- **THEN** 页面 MUST 继续展示旧数据，并显示失败提示与最近成功时间

#### Scenario: 首次加载失败
- **WHEN** 首次加载失败且无任何历史数据
- **THEN** 页面 MUST 显示明确的不可用状态与重试入口，MUST NOT 回退到 mock 数值

### Requirement: 信号口径与色彩映射

前端 MUST 使用真实信号口径 `bottom` / `top` / `none`，并按项目既定色彩系统呈现：底部（买入）信号使用薄荷绿系，顶部（卖出）信号使用珊瑚橙系，无信号使用中性灰。MUST NOT 使用 `buy` / `sell` 等旧口径字段。

#### Scenario: 信号类型映射
- **WHEN** 渲染某指数的当前信号
- **THEN** `bottom` MUST 呈现为底部/买入语义并使用薄荷绿系，`top` MUST 呈现为顶部/卖出语义并使用珊瑚橙系，`none` MUST 呈现为中性状态

### Requirement: 准确率展示必须带样本量

页面展示任何准确率时 MUST 同时展示触发次数、已判定样本数、未决数与统计区间；样本数不足时 MUST 显示小样本提示。MUST NOT 仅展示单一百分比，MUST NOT 只展示较宽松的一种口径。多持有期矩阵的每一格 MUST 独立满足上述要求，MUST NOT 用其他持有期的样本量代替。个位数样本 MUST 如实显示 `n=…`、Wilson 95% 区间与统计区间，MUST NOT 省略样本量。

#### Scenario: 准确率卡片
- **WHEN** 页面展示某指数的准确率
- **THEN** 卡片 MUST 同时包含触发次数、已判定样本数、未决数、统计起止区间、方向正确率与有效幅度率；当已判定样本数少于 30 时 MUST 显示小样本提示

#### Scenario: 逐格不复用样本量
- **WHEN** 30 日持有期格因持有期未满未决数较多
- **THEN** 该格 MUST 显示自身的触发次数、已判定样本数与未决数，MUST NOT 复制 5 日格的样本量

### Requirement: 候选信号与确认层数

页面 MUST 展示尚未确认的候选信号及其已通过层数（价格 / 动量 / 量能，0–3）。无候选时 MUST 显示空状态而非隐藏该区域。

#### Scenario: 候选列表
- **WHEN** 快照中存在候选信号
- **THEN** 列表 MUST 显示候选日期、指数、方向与已通过层数，且与已确认信号在视觉上区分

#### Scenario: 无候选
- **WHEN** 快照中不存在候选信号
- **THEN** 页面 MUST 显示明确的空状态文案

### Requirement: 页面数据一致性

同一快照 MUST 驱动所有页面的展示，切换页面 MUST NOT 触发重复的独立请求风暴；同一时刻不同页面展示的同一指数数值 MUST 一致。

#### Scenario: 页面切换不重复请求
- **WHEN** 用户在多个页面间切换
- **THEN** 前端 MUST 复用已获取的快照，仅在轮询周期到达时发起新请求

### Requirement: 指标总览指数图表主区

【指标总览】MUST 以七张指数图表作为主内容：同一快照中的 7 大宽基指数 MUST 分别展示收盘价折线、指数名称、最新收盘价与当日涨跌幅，且 MUST NOT 为缺少数据的指数显示编造或占位点位。桌面宽度下，7 张图卡 MUST 按固定的四行分组布局排列：第一行上证指数独占一整行，第二行科创50 与创业板指并排，第三行深证成指与沪深300 并排，第四行中证500 与中证1000 并排。

#### Scenario: 七个指数完整展示
- **WHEN** 快照中的指数列表包含 7 大宽基指数
- **THEN** 页面 MUST 同时渲染 7 张图表卡片，且每张小图的指数名称、收盘价与涨跌幅分别对应自身数据

#### Scenario: 桌面两列布局
- **WHEN** 用户在桌面宽度查看【指标总览】
- **THEN** 图表主区 MUST 按四行排列：第一行仅上证指数且横跨整行；第二行左为科创50、右为创业板指；第三行左为深证成指、右为沪深300；第四行左为中证500、右为中证1000；较窄屏幕 MUST 自动降为单列，MUST NOT 横向挤压或裁切图表

#### Scenario: 窄屏单列堆叠
- **WHEN** 屏幕宽度不足以容纳两列
- **THEN** 图卡 MUST 降为单列并按上证指数、科创50、创业板指、深证成指、沪深300、中证500、中证1000 的顺序依次堆叠，MUST NOT 横向挤压或裁切图表

#### Scenario: 某个指数无历史数据
- **WHEN** 任一指数的历史序列为空
- **THEN** 对应卡片 MUST 显示明确的空状态，其他指数图表 MUST 不受影响，且四行分组布局 MUST 保持卡片位置不变

### Requirement: 图表时间范围选择

图表主区 MUST 提供统一的时间范围下拉框，选项 MUST 依次为：近一个月、近三个月、近半年、近一年、近两年、近三年、全部。初始范围 MUST 为“近一年”；单次选择 MUST 同时作用于全部 7 张图，MUST NOT 要求用户逐张切换。

#### Scenario: 同步切换七张图
- **WHEN** 用户选择任一时间范围
- **THEN** 所有 7 张图 MUST 以同一最新交易日为基准，各自展示该范围内的实际交易日序列

#### Scenario: 选择全部
- **WHEN** 用户选择“全部”
- **THEN** 每张图 MUST 展示快照中已有的完整历史，并 MUST 显示实际覆盖起止日期与交易日数量

#### Scenario: 历史短于所选范围
- **WHEN** 某指数可展示历史短于所选范围
- **THEN** 该指数 MUST 按实际可得历史绘制并明确提示覆盖范围，MUST NOT 补充未来日期或编造数据

### Requirement: 指数图表信号标记

每张指数折线图 MUST 在可视时间范围内叠加该指数的信号标记：已确认的底部与顶部信号 MUST 全部显示，当前仍在确认窗口内的候选信号 MUST 显示。已确认信号与候选信号 MUST 在视觉形态与说明上明确区分；底部方向 MUST 使用项目既有薄荷绿语义，顶部方向 MUST 使用项目既有珊瑚橙语义。

#### Scenario: 已确认信号映射
- **WHEN** 某指数在时间范围内存在已确认信号
- **THEN** 图线 MUST 在对应交易日与触发价位置标记其方向，且 MUST NOT 将 `top` 或 `bottom` 转换为其他旧口径

#### Scenario: 候选信号可见且未确认
- **WHEN** 某指数存在当前候选信号
- **THEN** 图线 MUST 在候选日期与触发价位置显示该候选，且 MUST 标注为待确认/未确认，MUST NOT 渲染成已确认信号

#### Scenario: 范围内无信号
- **WHEN** 当前时间范围内没有任何已确认信号或当前候选
- **THEN** 图线 MUST 仍可正常展示走势，并 MUST 显示图例说明当前无信号标记，MUST NOT 显示空白的假标记

### Requirement: 图表信号信息与运行状态

信号标记的悬停或点击信息 MUST 至少包含日期、方向、状态与触发价；候选信号信息 MUST 同时包含价格、动量、量能三层确认的通过状态。盘中临时态 MUST 继续使用醒目提示，并与收盘正式态可区分。

#### Scenario: 已确认信号信息
- **WHEN** 用户查看任一已确认信号标记
- **THEN** 信息 MUST 明确标注“已确认”，并显示该信号的日期、方向与触发价

#### Scenario: 候选信号信息
- **WHEN** 用户查看任一候选信号标记
- **THEN** 信息 MUST 明确标注“待确认”，并分别显示价格、动量、量能三项的通过状态与候选已等待交易日数

#### Scenario: 折线点位悬停信息
- **WHEN** 用户将鼠标移入折线任意位置而非信号标记上
- **THEN** 信息 MUST 显示该交易日的日期与收盘价；若该交易日存在已确认信号或当前候选，MUST 在同一提示中追加对应信号的状态、方向、触发价（候选另含三层确认进度）

#### Scenario: 盘中临时数据
- **WHEN** 快照处于盘中临时态
- **THEN** 图表区域 MUST 显示盘中提示，盘中产生的信号 MUST 显示临时/未确认语义，且 MUST NOT 被表述为收盘后正式确认结果

### Requirement: 宽基指数页面入口迁移

前端 MUST 移除独立【宽基指数】导航入口与对应页面路由；访问旧 `/indices` 地址 MUST 自动跳转到【指标总览】首页。MUST NOT 保留两个仅数据来源不同的重复指数总览页面。

#### Scenario: 导航不含宽基指数入口
- **WHEN** 用户查看侧边导航
- **THEN** 导航 MUST 不再显示【宽基指数】菜单，且当前路由标题 MUST 不再将其作为可访问页面展示

#### Scenario: 旧地址自动跳转
- **WHEN** 用户打开旧地址 `/indices` 或直接刷新该地址
- **THEN** 应用 MUST 自动跳转到 `/`【指标总览】页面并正常展示，MUST NOT 显示空白页或 404

### Requirement: 指标总览多持有期矩阵卡片

【指标总览】MUST 以多持有期矩阵替换单一「已判定胜率」卡片：按 5 / 10 / 20 / 30 交易日持有期 × `bottom` / `top` 方向呈现，并可按研究段 / 独立验证段切换。每格 MUST 同时给出方向正确率、有效幅度率、触发次数（`n=…`）、已判定样本数、未决数、Wilson 区间与平均最大不利偏移。MUST NOT 再以单一百分比（如 97.4%）作为唯一准确率呈现。矩阵 MUST 遵循项目既有清新淡色风格（主色 `#3a9a6a`，辅色天蓝 / 薄荷绿 / 珊瑚橙）与既有字体、卡片、栅格规范，MUST NOT 引入第二套视觉语言。无数据的格 MUST 显示 `--` 或「暂无样本」，MUST NOT 显示 0% 或补造数值。页面 MUST 用业务语言解释浮亏约束（例如「信号后中途最多允许浮亏 5%，超出即判失败」）。

#### Scenario: 矩阵替换单一胜率
- **WHEN** 用户打开【指标总览】
- **THEN** 页面 MUST 呈现 4 持有期 × 2 方向的矩阵，MUST NOT 出现不带触发次数的单一「已判定胜率」百分比

#### Scenario: 每格字段齐全
- **WHEN** 查看 20 日 / `bottom` 格
- **THEN** 该格 MUST 显示方向正确率、有效幅度率、`n=…`、已判定样本数、未决数、Wilson 区间与平均最大不利偏移

#### Scenario: 无样本不补造
- **WHEN** 某格没有任何已判定样本
- **THEN** 该格 MUST 显示 `--` 或「暂无样本」，MUST NOT 显示 0% 或任何推测值

#### Scenario: 浮亏约束通俗说明
- **WHEN** 页面首次展示浮亏硬约束
- **THEN** 页面 MUST 显示通俗解释与示例（如「3000 点信号，中途最低不跌破 2850 点」），MUST NOT 只显示技术字段名

### Requirement: 统计覆盖范围标注与拐点对照

页面 MUST 明确标注准确率统计所覆盖的标的清单与标的数，并 MUST 与【指标总览】展示的 7 张指数图卡范围可区分，MUST NOT 让读者误以为图示信号数量与统计样本数量相同。折线图 MUST 在保留确认日 marker 的同时，以视觉上可区分的样式标注拐点基准日与拐点自然确认日，MUST NOT 把拐点基准日误呈现为信号发出日。图例 MUST 说明三者的区别，MUST NOT 省略。切换页面 MUST 复用同一快照，MUST NOT 触发重复请求。

#### Scenario: 统计范围可区分
- **WHEN** 准确率矩阵合并了扩展标的池
- **THEN** 页面 MUST 显示「统计覆盖 N 个标的」并列出清单，且与 7 张图卡的标题范围明确区分

#### Scenario: 拐点日与信号日可区分
- **WHEN** 折线图同时呈现拐点基准日、自然确认日与信号确认日
- **THEN** 三者 MUST 使用不同标记样式并在图例中说明，MUST NOT 用同一 marker 样式

#### Scenario: 不误报为信号发出日
- **WHEN** 用户 hover 拐点基准日标记
- **THEN** 提示 MUST 说明这是事后标注的拐点基准，MUST NOT 表述为「信号发出日」
