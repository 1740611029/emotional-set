# sector-trend-explorer Specification

## Purpose
提供板块维度的趋势浏览能力：让用户按单层行业板块清单（东财行业板块 31 个行业）查看走势曲线与当前四态（多头 / 退潮 / 空头 / 反转）、持续天数与有向强度，并能读懂强度数值的含义与算法构成；每个板块的状态均为其自身日线的独立判定结果。

## Requirements

### Requirement: 单层行业板块列表与导航

页面 MUST 以单层行业板块列表展示快照中的全部板块：列表项 MUST 含板块名称、代码、四态状态标签、有向强度与持续天数；选中某板块后 MUST 在详情区展示其走势与摘要。页面 MUST 默认选中一个板块（优先选中强度最高者）。页面 MUST NOT 出现任何一级/二级层级组织、父子展开、子板块列表或二级弹窗入口。

#### Scenario: 默认展示板块全集
- **WHEN** 用户进入板块趋势页
- **THEN** 页面 MUST 列出快照中全部板块，并默认选中其中一个（优先强度最高者），右侧展示其详情

#### Scenario: 切换选中板块
- **WHEN** 用户点击列表中的另一板块
- **THEN** 详情区 MUST 切换为该板块的状态、强度与走势数据，MUST NOT 残留上一板块的数值或序列

### Requirement: 四态语义与标签固定

页面 MUST 使用固定的四态取值与中文标签：`bull` → 多头、`warn` → 退潮、`bear` → 空头、`rise` → 反转。四态 MUST 各自对应可区分的视觉标识，且 MUST NOT 使用"买入""卖出"等交易指令性措辞。

#### Scenario: 状态标签映射
- **WHEN** 渲染任一板块的状态
- **THEN** 标签 MUST 为"多头 / 退潮 / 空头 / 反转"之一，且同一状态在列表、详情、图例中的标签与配色 MUST 一致

#### Scenario: 未分类状态
- **WHEN** 某板块的 `state` 为空或为 `unclassified`
- **THEN** 页面 MUST 显示"数据不足/未分类"，MUST NOT 赋予四态之一的颜色，且 MUST NOT 计入任何四态的筛选结果

### Requirement: 强度数值语义与构成解释

页面 MUST 把方向强度呈现为 -50–+50 的"有向强度"，并 MUST 提供可展开的解释面板，说明：0 为中性，正值表示相对偏强，负值表示相对偏弱，绝对值越大表示偏离中性越远；所有状态 MUST 使用同一公式，MUST NOT 因 `bull` / `rise` / `bear` / `warn` 状态而取反。强度由"近 20 日区间位置分"与"相对 60 日均线偏离分"两项构成，两项原始构成分仍为 0–100。

#### Scenario: 数值口径可见
- **WHEN** 用户查看任一板块的强度
- **THEN** 页面 MUST 展示保留一位小数的有向强度，并 MUST 提供进入解释面板的入口，说明 -50–+50、0 中性与正负方向含义

#### Scenario: 构成分解可复算
- **WHEN** 用户展开强度解释面板
- **THEN** 面板 MUST 显示该板块的 `range_position` 与 `ma_score` 两项构成分，并给出可复算算式 `strength = (range_position + ma_score) / 2 - 50`；零通道异常 MUST 单独说明固定为 0

#### Scenario: 空头与退潮的语义说明
- **WHEN** 某板块状态为 `bear` 或 `warn`
- **THEN** 页面 MUST 直接展示按统一公式计算的有向强度，MUST NOT 再显示"取反""空头方向强度"或"数值越高表示下跌越强"的旧口径说明

#### Scenario: 跨状态不可比提示
- **WHEN** 页面同时展示多种状态的强度
- **THEN** 页面 MUST 按同一正负方向口径展示，MUST NOT 显示"强度只在同一状态内可比，跨状态数值不可直接比较"的旧提示

#### Scenario: 数据异常
- **WHEN** 某板块 `data_anomaly` 为真（近 20 日高低价相同）
- **THEN** 页面 MUST 标注强度为固定中性值 0，并 MUST NOT 将其作为强度排序的有效依据

### Requirement: 筛选、排序与检索

页面 MUST 支持按四态筛选、按有向强度排序，并支持按板块名称或代码检索。筛选与排序 MUST 实时作用于列表，且 MUST 展示当前筛选结果的数量。

#### Scenario: 按状态筛选
- **WHEN** 用户选择"多头"筛选
- **THEN** 列表 MUST 只保留 `state` 为 `bull` 的板块，并显示命中数量；选中项被筛除时 MUST 自动切换到列表首项或显示未选中态

#### Scenario: 按强度排序
- **WHEN** 用户选择按强度排序且列表包含多种状态
- **THEN** 列表 MUST 按有向 `strength` 数值降序排列，`strength` 为空或数据异常的板块 MUST 排在末尾，且 MUST NOT 使用绝对值或按状态取反后的数值排序

#### Scenario: 检索无结果
- **WHEN** 用户输入的检索词不匹配任何板块
- **THEN** 页面 MUST 显示"无匹配板块"空状态，MUST NOT 显示空白列表

### Requirement: 板块走势图

页面 MUST 展示选中板块最近一段交易日的收盘走势，并 MUST 在同一图表中标注该区间内每日的四态变化。图表 MUST 支持时间范围切换（60 / 120 / 250 个交易日），MUST 支持悬停查看单日日期、收盘价与当日状态。图表 MUST 提供可见图例，至少包含“收盘”和“MA60（60日均线）”；MA60 图例 MUST 对应蓝色虚线，并明确表示最近 60 个交易日收盘价的简单算术平均值，MUST NOT 被表述为强度或交易信号。

#### Scenario: 走势与状态带同时呈现
- **WHEN** 用户选中某板块
- **THEN** 图表 MUST 展示该板块收盘序列，并 MUST 以背景色带或等效方式标出区间内每日四态，且图例 MUST 与状态标签一致

#### Scenario: MA60 图例含义明确
- **WHEN** 用户查看任一 60 / 120 / 250 日板块走势图
- **THEN** 可见图例 MUST 将蓝色虚线标为“MA60（60日均线）”，且 MUST 同时保留“收盘”图例，使用户无需查看外部文档即可区分价格线与均线

#### Scenario: 图例不遮挡图表内容
- **WHEN** 图表在当前页面尺寸下渲染或调整尺寸
- **THEN** 图例 MUST 位于图表的独立布局区域内，MUST NOT 遮挡收盘价、MA60、坐标读数或时间范围操作

#### Scenario: MA60 历史窗口不足
- **WHEN** 当前序列存在不足 60 个有效收盘价的区间
- **THEN** 对应区间 MUST 继续保持 MA60 无数值，MUST NOT 补造均线点；图例 MUST 保留“MA60（60日均线）”说明

#### Scenario: 时间范围切换
- **WHEN** 用户切换时间范围
- **THEN** 图表 MUST 按所选交易日数量重绘，且 MUST NOT 触发整页重新加载

#### Scenario: 悬停读数
- **WHEN** 用户将指针移动到图表某一交易日
- **THEN** 图表 MUST 显示该日日期、收盘价与当日状态

#### Scenario: 历史长度不足
- **WHEN** 选中板块可用历史少于所选时间范围
- **THEN** 图表 MUST 按实际可用长度绘制并提示实际覆盖区间，MUST NOT 插值或补造缺失交易日

#### Scenario: 状态序列缺失
- **WHEN** 某板块无状态序列（历史不足 60 日或数据异常）
- **THEN** 图表 MUST 仍绘制可用收盘序列，并 MUST NOT 绘制状态色带

### Requirement: 状态摘要与数据时点

详情区 MUST 展示选中板块的当前状态、状态持续天数、有向强度数值、统一强度口径与数据所属交易日。MUST NOT 展示无法由数据支撑的推断值，也 MUST NOT 再展示强度是否按多空取反。

#### Scenario: 摘要字段完整
- **WHEN** 用户查看任一板块详情
- **THEN** 摘要 MUST 包含状态标签、持续天数、保留一位小数的有向强度、强度口径（有向/中性）与 `as_of`

#### Scenario: 数据滞后提示
- **WHEN** 某板块 `data_lag` 为真
- **THEN** 页面 MUST 显示该板块的数据日期早于 `as_of` 的提示

### Requirement: 四态方向胜率验证展示

页面 MUST 展示快照自带板块评估的**四态方向胜率**：按研究段 / 验证段 × 10 日 / 20 日 × 四态（`bull` / `warn` / `bear` / `rise`）呈现，每格 MUST 同时给出胜率、已判定样本量与 Wilson 95% 区间，MUST NOT 只给出不带样本量的单一百分比。该区块的口径为该段全部行业板块的统计，MUST NOT 随当前选中板块变化，也 MUST NOT 被表述为某个板块自身的胜率。

四态的标签与配色 MUST 与该页列表、详情与图例保持一致。样本不足的格子 MUST 如实给出该格已判定样本量（形如 `n=…`）与 Wilson 95% 区间，MUST NOT 静默省略样本量。某状态无已判定样本时 MUST 显示无数据占位，MUST NOT 显示 0% 或任何补造数值。

区块 MUST 展示说明文字：板块趋势为描述性分类、方向胜率不代表交易收益，且验证段为事后观察、不构成独立验证；MUST NOT 出现"买入""卖出""胜率极高""可交易"等指令性或收益暗示措辞。

#### Scenario: 四态统计可见
- **WHEN** 用户查看板块趋势页且评估数据可用
- **THEN** 页面 MUST 同时呈现研究段与验证段、10 日与 20 日窗口、四个状态的胜率与已判定样本量

#### Scenario: 每格带样本量与区间
- **WHEN** 渲染任一「状态 × 窗口」格子
- **THEN** 该格 MUST 显示胜率、已判定样本量（形如 `n=…`）与 Wilson 95% 区间，MUST NOT 只显示一个百分比

#### Scenario: 小样本如实披露
- **WHEN** 某格子的样本不足
- **THEN** 页面 MUST 在该格如实显示已判定样本量（形如 `n=…`）与 Wilson 95% 区间，MUST NOT 省略样本量

#### Scenario: 无样本不显示 0%
- **WHEN** 某状态在某段某窗口没有已判定样本
- **THEN** 该格 MUST 显示无数据占位，MUST NOT 显示 0% 或其他推断值

#### Scenario: 不随选中板块变化
- **WHEN** 用户在板块列表中切换选中项
- **THEN** 该区块的数值 MUST 保持不变（口径为全部行业板块），MUST NOT 显示为当前选中板块的胜率

#### Scenario: 评估缺失时的降级
- **WHEN** 快照未携带板块评估或结构为空
- **THEN** 页面 MUST 显示评估尚未生成的提示，MUST NOT 显示示例数值或空缺表格

#### Scenario: 说明与风险提示
- **WHEN** 用户查看该区块
- **THEN** 页面 MUST 可见地展示描述性分类、方向胜率不代表交易收益、验证段非独立验证的说明

### Requirement: 描述性定位与风险提示

四态 MUST 呈现为描述性分类，MUST NOT 呈现为买入/卖出建议或预期收益。页面 MUST 展示数据自带的说明（板块趋势为描述性分类、方向胜率不代表交易收益），且 MUST NOT 省略该提示。

#### Scenario: 说明可见
- **WHEN** 用户查看板块趋势页
- **THEN** 页面 MUST 可见地展示"描述性分类、不代表交易收益"的说明文案

#### Scenario: 无交易指令
- **WHEN** 审查页面文案与交互
- **THEN** MUST NOT 出现"买入""卖出""建仓""目标价"等指令性措辞

### Requirement: 加载、失败与陈旧降级

页面 MUST 复用站点统一数据层的加载、失败与陈旧降级行为：首次加载显示加载态；请求失败时保留上一次成功数据并提示失败原因；数据陈旧时显示陈旧提示与最近成功时间。MUST NOT 回退到编造的示例数值。

#### Scenario: 首次加载
- **WHEN** 用户首次打开板块趋势页且数据尚未返回
- **THEN** 页面 MUST 显示加载态，MUST NOT 显示任何数值

#### Scenario: 请求失败保留旧数据
- **WHEN** 数据请求失败且存在上一次成功数据
- **THEN** 页面 MUST 继续展示旧数据并显示失败提示与最近成功时间
