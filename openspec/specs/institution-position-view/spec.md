# institution-position-view Specification

## Purpose
定义"机构多空单"页面的展示与交互契约：把中金所前 20 会员的股指期货多空持仓加工为机构级净持仓序列，并与其后一个交易日的沪深300 走势做同向/对冲对照，供用户以列表与折线图查看历史与当日情况。

## Requirements

### Requirement: 机构分组与固定展示顺序

页面 MUST 将机构固定分为三组并按「中信期货 → 国泰君安 → 其他机构」的顺序展示（中信期货在前），MUST NOT 因数据缺失而改变分组或顺序。三家分组 MUST 互斥：同一会员 MUST 只归属一组。"其他机构" MUST 明确标注其口径为"前 20 会员中除国泰君安、中信期货外的合计"。

#### Scenario: 固定三家分组
- **WHEN** 页面加载完成且数据可用
- **THEN** 列表与图例 MUST 依次出现"中信期货""国泰君安""其他机构"三组，且组名旁 MUST 可查看各自口径说明

#### Scenario: 某组当日无数据
- **WHEN** 某一机构在某交易日无持仓记录
- **THEN** 该组 MUST 仍出现在列表中并显示"无数据"状态，MUST NOT 被隐藏或与其他组合并

### Requirement: 品种维度切换与汇总口径声明

页面 MUST 提供"四品种汇总"与 IF / IC / IH / IM 分品种共 5 个视图，默认 MUST 为四品种汇总。汇总视图 MUST 在可视区域内声明：汇总值为各品种持仓手数直接相加，未按合约乘数折算为名义金额，因此不可用于跨品种规模比较。

#### Scenario: 默认汇总视图
- **WHEN** 用户首次进入页面
- **THEN** 品种选择 MUST 处于"汇总"状态，且汇总口径声明 MUST 无需展开即可见

#### Scenario: 切换分品种
- **WHEN** 用户选择 IF（或 IC / IH / IM）
- **THEN** 列表、折线图与同向率摘要 MUST 全部切换为该品种数据，且汇总口径声明 MUST 相应隐藏或改为品种口径说明

### Requirement: 当日快照表

页面 MUST 以表格展示所选品种视图下三家机构的当日情况，每行 MUST 包含：多单（持买单量）、空单（持卖单量）、净持仓、净持仓较上一交易日变化、次日沪深300 涨跌幅、同向/对冲判定。当次日数据尚未产生时，该行 MUST 显示"待判定"而非空值或推测值。

表格 MUST 额外提供两列滚动窗口同向率：「近 10 个交易日同向率」与「近 20 个交易日同向率」。窗口 MUST 取当前品种同向/对冲关系序列尾部 10 / 20 个交易日；待判定与无数据 MUST NOT 计入分母；每个窗口 MUST 同时展示百分比与已判定样本数，样本量偏少时 MUST 如实披露，MUST NOT 仅以百分比呈现。

#### Scenario: 已判定日的快照行
- **WHEN** 当日持仓已生成且其次日沪深300 收盘数据已存在
- **THEN** 该行 MUST 显示次日涨跌幅数值与"同向"或"对冲"标签，标签 MUST 与判定规则一致

#### Scenario: 次日数据未产生
- **WHEN** 当日为最新交易日，其次日行情尚不存在
- **THEN** 次日涨跌幅与关系列 MUST 显示"待判定"，MUST NOT 显示为同向、对冲或 0

#### Scenario: 滚动窗口同向率列
- **WHEN** 当日快照表渲染完成
- **THEN** 表格 MUST 出现"近10个交易日同向率""近20个交易日同向率"两列，取值 MUST 为窗口内同向天数 ÷ 窗口内已判定天数（同向 + 对冲），待判定与无数据 MUST NOT 计入分母

#### Scenario: 窗口同向率带样本量
- **WHEN** 用户查看任一机构的滚动窗口同向率
- **THEN** 同一视觉单元内 MUST 同时出现百分比与已判定样本数；窗口内已判定样本偏少时 MUST 如实披露，MUST NOT 省略样本量或补造数值

### Requirement: 历史明细列表

页面 MUST 将历史明细拆分为三个独立列表分别展示：中信期货、国泰君安、其他机构，三个列表 MUST 全部同时可见且互不折叠合并。每个列表 MUST 以标题标明机构名称；「其他机构」列表 MUST 沿用其口径说明（前 20 会员中除国泰君安、中信期货外的合计）。每行 MUST 包含日期、品种、多单、空单、净持仓、净持仓变化、次日沪深300 涨跌幅与关系判定；因每个列表仅含单一机构，行内 MUST NOT 重复展示机构列。三个列表 MUST 共享品种视图与日期区间筛选，MUST 各自独立分页或滚动加载，MUST NOT 一次性渲染全部历史行，MUST NOT 保留独立的机构下拉筛选。每个列表内 MUST 默认按日期倒序排列；某一机构在筛选区间内无记录时，该列表 MUST 显示空状态文案，其余列表 MUST 不受影响。三个列表的表格区域 MUST 统一固定高度 250px：行数超出可视高度时 MUST 在表格区域内部纵向滚动且表头 MUST 保持可见，MUST NOT 撑高页面；行数不足或无数据时该区域 MUST 仍保持 250px 高度，保证三个列表视觉对齐。

#### Scenario: 默认倒序与分页
- **WHEN** 用户进入历史明细区域且未设置筛选
- **THEN** 每个机构列表 MUST 以日期倒序展示，且单页渲染行数 MUST 有上限并提供翻页或滚动加载

#### Scenario: 筛选后无结果
- **WHEN** 用户设置的筛选组合没有任何匹配记录
- **THEN** 三个列表 MUST 均显示明确的空状态文案，MUST NOT 显示上一轮筛选的残留数据

#### Scenario: 三个列表同时呈现
- **WHEN** 用户进入历史明细区域且未设置筛选
- **THEN** 页面 MUST 依次展示中信期货、国泰君安、其他机构三个独立列表，每个列表 MUST 以日期倒序展示该机构记录，且每个列表单页渲染行数 MUST 有上限并提供翻页或滚动加载

#### Scenario: 筛选对所有列表生效
- **WHEN** 用户切换品种视图或设置日期区间
- **THEN** 三个列表 MUST 同时切换为该品种、该区间下各自机构的记录，且每个列表的分页 MUST 重置到第一页

#### Scenario: 单一机构无匹配记录
- **WHEN** 某一机构在当前筛选组合下没有匹配记录，但其他机构有
- **THEN** 该机构列表 MUST 显示明确的空状态文案，其余列表 MUST 正常展示，MUST NOT 显示上一轮筛选的残留数据

#### Scenario: 机构口径可辨
- **WHEN** 用户查看任一历史明细列表
- **THEN** MUST 无需查看行内机构列即可识别该列表所属机构；「其他机构」列表 MUST 可查看其口径说明

#### Scenario: 固定高度内部滚动
- **WHEN** 某一机构列表当前页行数超出 250px 可视高度
- **THEN** 该表格区域 MUST 在 250px 高度内纵向滚动，滚动时表头 MUST 保持可见，页面整体高度 MUST NOT 因行数增多而变高

#### Scenario: 行数不足时高度一致
- **WHEN** 某一机构列表当前筛选下行数不足或为空
- **THEN** 该列表的表格/空状态区域 MUST 仍保持 250px 高度，三个列表区域高度 MUST 一致

### Requirement: 净持仓与次日走势折线图

页面 MUST 提供折线图，同一图内 MUST 同时呈现所选机构的净持仓序列与大盘走势对照。大盘走势 MUST 以**指数收盘价点位折线**呈现（而非涨跌幅百分比），且 MUST 同时叠加**上证指数**与**沪深300** 两条收盘价序列。图卡标题 MUST 显示“净持仓与大盘 走势对照”。净持仓序列 MUST 保持在左侧“净持仓（手）”轴，指数收盘价序列 MUST 使用右侧“指数点位”轴。图表 MUST 支持按机构筛选、按时间范围（近 20 / 60 / 120 个交易日）切换，并 MUST 具备图例、坐标轴单位说明与悬停数值提示；数据缺失的日期 MUST 表现为断点，MUST NOT 以插值或零值连接。

上证指数收盘价序列 MUST 仅用于图表展示，MUST NOT 改变页面其余统计口径：次日涨跌、同向/对冲判定、同向率与交易日历仍 MUST 以沪深300 为唯一基准，其数值 MUST NOT 因新增上证指数展示序列而发生任何变化。

#### Scenario: 双序列同时可见
- **WHEN** 用户选择任一机构与任一时间范围
- **THEN** 图中 MUST 同时出现该机构净持仓折线、上证指数收盘价折线与沪深300 收盘价折线，且各序列的日期轴 MUST 对齐

#### Scenario: 缺失数据断点
- **WHEN** 某交易日在所选机构净持仓或任一指数收盘价序列中缺失
- **THEN** 该日期 MUST 显示为断点，且悬停提示 MUST 标明该日数据缺失

#### Scenario: 右侧轴为收盘价点位而非涨跌幅
- **WHEN** 用户查看对照图右侧指数序列
- **THEN** 右侧纵轴 MUST 标注为指数点位、悬停数值 MUST 以点位呈现，MUST NOT 显示为涨跌幅百分比

#### Scenario: 图卡标题更新
- **WHEN** 用户进入机构多空单页面并滚动至对照图区域
- **THEN** 图卡标题 MUST 显示“净持仓与大盘 走势对照”，MUST NOT 出现“净持仓与沪深300 走势对照”

#### Scenario: 展示口径与统计基准分离
- **WHEN** 页面叠加展示上证指数收盘价序列
- **THEN** 当日快照与历史明细的“次日沪深300”涨跌幅、同向/对冲判定与同向率 MUST 与仅以沪深300 为基准时完全一致，MUST NOT 因展示序列变化而改变

### Requirement: 同向率摘要必须带样本量与区间

页面 MUST 为每个机构 × 品种组合展示同向率摘要，且每个同向率 MUST 同时展示已判定样本数、同向天数、对冲天数与统计起止区间。"待判定"日期 MUST NOT 计入分母。样本量偏少时 MUST 如实显示已判定样本数与统计区间。

#### Scenario: 同向率与样本量同时可见
- **WHEN** 页面展示任一机构的同向率
- **THEN** 同一视觉单元内 MUST 同时出现百分比、已判定样本数、同向/对冲天数与统计区间

#### Scenario: 小样本如实披露
- **WHEN** 某机构 × 品种的已判定样本数偏少
- **THEN** 该摘要 MUST 如实显示已判定样本数与统计区间，MUST NOT 仅以百分比呈现

#### Scenario: 待判定不计入分母
- **WHEN** 某区间内存在次日数据尚未产生的日期
- **THEN** 这些日期 MUST 从同向率分母中排除，且 MUST 在摘要中单独说明待判定条数

### Requirement: 事后评估语义与禁用预测化表述

页面 MUST 明确标注"次日走势为事后统计对照，不构成预测或交易信号"。页面 MUST NOT 出现买入、卖出、建仓、目标价等交易建议式表述，MUST NOT 将同向/对冲关系渲染为方向性预测。当日尚未产生次日数据的记录 MUST NOT 参与任何比率计算。

#### Scenario: 页面常驻声明
- **WHEN** 用户查看页面任一区域
- **THEN** 页面 MUST 在首屏可见位置提供事后统计声明，且该声明 MUST 不依赖悬停或展开才能看到

#### Scenario: 禁止建议式文案
- **WHEN** 审查页面全部文案与标签
- **THEN** MUST NOT 出现买入/卖出/加仓/减仓等建议式措辞，同向/对冲 MUST 仅以"历史对照"语义呈现

### Requirement: 口径限制披露

页面 MUST 披露以下口径限制且无需跳转外部文档即可查看：数据为中金所前 20 会员持仓排名，非全市场持仓；多单与空单为单边持仓量；数值单位为手；不同品种合约乘数不同。页面 MUST 同时展示数据所属交易日与最近更新时间。

#### Scenario: 口径说明可达
- **WHEN** 用户查看页面
- **THEN** MUST 能直接看到前 20 会员、单边口径、单位与品种乘数差异四项说明

#### Scenario: 数据时点可见
- **WHEN** 页面展示任一表格或图表
- **THEN** 页面 MUST 显示该数据对应的交易日与最近更新时间

### Requirement: 加载、失败与陈旧降级

页面 MUST 复用既有数据层的加载、失败与陈旧处理语义：首次加载显示加载态；请求失败保留上一次成功数据并提示失败原因；数据陈旧时显示陈旧提示与最近成功时间。MUST NOT 以 mock 或占位数值替代真实数据。

#### Scenario: 首次加载无数据
- **WHEN** 首次请求失败且无任何历史数据
- **THEN** 页面 MUST 显示不可用状态与重试入口，MUST NOT 渲染任何数值

#### Scenario: 数据陈旧
- **WHEN** 接口返回数据陈旧标记
- **THEN** 页面 MUST 显示陈旧提示与最近成功时间，且 MUST 保留当前已展示的数据
