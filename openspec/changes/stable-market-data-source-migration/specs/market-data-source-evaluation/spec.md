# Spec Delta

## Purpose

定义在更换生产行情价格口径之前，对候选免费公开数据源进行可量化稳定性与口径可比性测试的契约，使「是否换源」由带样本量与统计区间的实测结论决定，而不是由接口偶发故障或主观印象决定；同时保证测试过程本身不触碰任何生产数据与信号产物。

## ADDED Requirements

### Requirement: 候选源范围与登记

系统 MUST 只把免费、公开、无需注册或凭据的行情源纳入生产候选清单，且 MUST 同时评估两类候选：同一数据发行方的其他接口或请求通道、以及其他数据发行方。每个候选 MUST 登记来源标识、接口或通道说明、复权口径、字段与单位、可覆盖的起止日期与是否需要凭据；需要凭据的源 MUST 被排除且记录排除原因。候选清单与测试产物 MUST 落在独立研究目录，MUST NOT 写入任何生产原始数据目录或生产产物。

#### Scenario: 需凭据的源被排除

- **WHEN** 某候选源要求注册账号、令牌或付费才能取到完整历史
- **THEN** 该源 MUST NOT 出现在生产候选清单中，报告 MUST 给出排除原因

#### Scenario: 同一发行方的其他通道入选

- **WHEN** 某候选与现用源来自同一发行方但走不同接口或请求通道
- **THEN** 该候选 MUST 作为独立条目登记并参与同一套测试，MUST NOT 因发行方相同而合并或跳过

#### Scenario: 测试不触碰生产

- **WHEN** 运行候选源稳定性测试
- **THEN** 生产原始数据目录与三份生产产物的内容和修改时间 MUST 保持不变

### Requirement: 稳定性测试口径

系统 MUST 在预先声明的观察窗口内，对每条受影响的数据线分别重复取数并记录：总请求数、成功数、限流或失败数、响应延迟分位数、当日日线首次可获取时刻，以及触发限流后的恢复时长。观察窗口 MUST 覆盖不少于预先声明的交易日数，且 MUST 包含收盘后各固定补齐时刻的取数尝试。所有比率 MUST 同时给出样本量与统计区间；单次成功或单个交易日的表现 MUST NOT 被表述为稳定性结论。

#### Scenario: 观察窗口不足不得出结论

- **WHEN** 某候选的有效观测交易日数少于预先声明的下限
- **THEN** 报告 MUST 标注「样本不足，暂不能判断」，MUST NOT 给出达标结论

#### Scenario: 比率带样本量与区间

- **WHEN** 报告某候选的取数成功率或限流率
- **THEN** 同一处 MUST 给出总请求数、成功数、统计起止日期与观察窗口内的交易日数

#### Scenario: 限流恢复时长可核查

- **WHEN** 某候选在测试期间触发限流
- **THEN** 报告 MUST 记录触发时刻、恢复可用时刻与间隔时长，MUST NOT 用重试成功掩盖该次限流

#### Scenario: 定稿时刻被记录

- **WHEN** 观察窗口内某个交易日的日线首次可获取
- **THEN** 报告 MUST 记录该交易日与首次可获取时刻，供调度时刻校准使用，MUST NOT 以「当天曾取到」代替具体时刻

### Requirement: 口径可比性门槛

候选源 MUST 与现用生产口径逐项可比：板块 MUST 与固化的 31 个单层行业一一对应，ETF MUST 与核心 6 只标的逐一对应，复权方式、字段顺序与价格或成交额单位 MUST 保持一致。系统 MUST 输出新旧源逐日收盘涨跌幅差异、板块四态一致率与翻转类型分布、ETF 放量日与级别差异，并 MUST 给出可比交易日数、行业数或标的数、统计区间与 Wilson 95% 区间。任一清单无法一一对应时 MUST 判定为不可比，MUST NOT 按名称近似匹配后继续评估。

#### Scenario: 清单缺项判不可比

- **WHEN** 某候选源缺少现行 31 个行业中的任一个，或缺少核心 6 只 ETF 中的任一只
- **THEN** 该候选 MUST 被判定为不可比，MUST NOT 进入切换候选，报告 MUST 列出缺失项

#### Scenario: 对照带样本量与区间

- **WHEN** 输出板块四态一致率或 ETF 放量日差异
- **THEN** 同一处 MUST 给出可比交易日数、行业数或标的数、统计起止日期与 Wilson 95% 区间

#### Scenario: 禁止按名称近似匹配

- **WHEN** 候选源返回的板块或标的名称与固化清单存在差异
- **THEN** 系统 MUST 报错并保留上一版数据，MUST NOT 自动改用名称相近的其他板块或标的

### Requirement: 切换门槛与不切换结论

切换门槛 MUST 在测试开始前声明并冻结，至少包含取数成功率下限、限流率上限、延迟上限、日线定稿时刻要求与口径可比性要求；门槛 MUST NOT 在看到测试结果后调整。任何候选未同时满足全部门槛时 MUST NOT 切换生产主源，系统 MUST 保留现用源并输出明确的「未达标」结论与逐项实测值。达标候选多于一个时 MUST 记录选择依据。测试报告 MUST 作为独立研究产物落盘，删除报告后重建的生产产物 MUST 与删除前逐条一致。

#### Scenario: 未达标不切换

- **WHEN** 全部候选中有源通过了稳定性但未通过口径可比性
- **THEN** 生产主源 MUST 保持不变，报告 MUST 标注未达标项及实测值，MUST NOT 以「部分达标」推广

#### Scenario: 门槛不得事后调整

- **WHEN** 测试完成后有人下调成功率下限以使某候选达标
- **THEN** 该调整 MUST 被拒绝或作为新一轮独立测试重新声明，MUST NOT 追溯适用于本轮结论

#### Scenario: 报告不进生产链路

- **WHEN** 删除全部候选源测试报告与测试缓存后重建生产产物
- **THEN** 三份生产产物 MUST 与删除前逐条一致
