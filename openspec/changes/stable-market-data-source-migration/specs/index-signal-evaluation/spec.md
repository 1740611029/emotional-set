# Spec Delta

## MODIFIED Requirements

### Requirement: 准确率口径变更留痕

本次主胜率口径更换 MUST 输出新旧对照：在**同一段历史、同一标的池、同一批信号**上分别按旧口径（均线反转）与新矩阵口径计算，报告 MUST 给出两种口径的成功数、已判定样本数、未决数与准确率，并记录变更原因与用户确认的口径选择。旧口径结果 MUST 保留为可复算的历史基线，MUST NOT 被删除或覆盖。

此外，**价格口径数据源更换** MUST 输出换源前后的信号与准确率对照：在**同一段历史、同一标的池、同一判定规则与同一冻结参数**上，分别用旧源日线与在用主源日线重算，按研究段 / 独立验证段 × 5 / 10 / 20 / 30 交易日 × `bottom` / `top` 逐格给出触发次数、已判定样本数、成功数、失败数、未决数、方向正确率、有效幅度率、Wilson 95% 区间与统计起止日期，并 MUST 给出信号日期集合的增删条目与逐条归因。该对照 MUST 明确标注为「输入口径变更对照，非算法改进」，MUST NOT 把差异表述为准确率提升或策略优化，MUST NOT 用换源后的结果回填或重写旧源口径下的历史结论。

#### Scenario: 新旧口径并列可复算

- **WHEN** 生成本次变更的对照报告
- **THEN** 报告 MUST 同时给出旧口径 75/77 与新口径各持有期矩阵，并注明两者不可直接比较及其原因

#### Scenario: 旧基线保留

- **WHEN** 新口径上线后需要回溯历史结论
- **THEN** 系统 MUST 仍能按旧口径复算并输出原结果，MUST NOT 因字段结构调整而丢失

#### Scenario: 换源对照逐格带样本量

- **WHEN** 输出换源前后某个「段 × 持有期 × 方向」格的对比
- **THEN** 该格 MUST 同时给出新旧两侧的触发次数、已判定样本数、未决数、方向正确率、Wilson 95% 区间与统计起止日期，MUST NOT 只给两个百分比

#### Scenario: 信号集合差异可归因

- **WHEN** 换源后某段历史的信号日期集合与旧源不同
- **THEN** 报告 MUST 逐条列出新增与消失的信号及其日期、指数代码与差异来源，MUST NOT 以汇总数量代替明细

#### Scenario: 差异不表述为改进

- **WHEN** 换源后某格准确率高于旧源
- **THEN** 报告 MUST 标注该差异来自输入口径变化、不构成算法改进结论，MUST NOT 使用「提升」「优化」等表述作为结论

#### Scenario: 冻结参数不重调

- **WHEN** 对照显示换源后验证段结果不如旧源
- **THEN** 冻结参数、阈值与幅度线 MUST 保持不变，MUST NOT 用该对照结果反向调参后作为同一轮结论报告
