# Proposal

## Why

【龙虎榜知名游资】页当前由唯一的 `buildViewTraders()` 以 `EXIT_MARK_DAYS = 3` 做「在场过滤」：某（游资, 个股）配对自 `exit_date` 起超过 **3 个交易日**，其操作记录与离场标记就被整段隐藏，页面没有回看入口。该过滤输出被三个 Tab 共用（游资总览、每日动向、个股游资总览）。用户希望把保留期统一放宽到 **5 个交易日**，并提供按需回看更早离场个股的开关；但【每日动向】要求保持原有展示不变。

实测产物（`as_of = 2026-11-13`，24 个交易日、488 个离场配对）：182 个配对在 0~5 个交易日内、306 个已 ≥6 个交易日；阈值由 3 日放宽到 5 日会让游资总览多 1 张卡片（21 → 22）、可见操作记录多 77 行（355 → 432，涉及 16 个交易日）。因此「默认隐藏 + 开关回看」是必要的。

本变更只调整**展示过滤与交互**，不改动任何在场判定算法、数据口径或信号链路。

## What Changes

- 【游资总览】与【个股游资总览】两个 Tab 的离场过滤阈值**统一改为 5 个交易日**，彻底取消 3 日这道线；起算日固定为产物已有的 `exit_date`（判定成立日），天数按 `trading_dates` 序号差计算；`已清仓 / 疑似清仓 / 已离场` 三种状态一视同仁。
- 具体边界：距 `exit_date` 0~5 个交易日 → 保留该配对的操作记录 **与**离场标记；第 6 个交易日起 → 默认隐藏整个配对。举例：`as_of = 2026-11-13`、`exit_date = 2026-11-06`（相隔 5 个交易日）仍展示；`exit_date = 2026-11-05`（相隔 6 个交易日）默认隐藏。
- 在【游资总览】与【个股游资总览】两个 Tab **各放一个**「显示 / 隐藏 5 日外离场个股（N）」切换按钮，二者共享同一个页面级开关状态，**默认隐藏**；开启后回显被隐藏的配对并照常显示其离场状态标记。N 为被隐藏配对涉及的去重股票代码数的精确计数（由过滤结果直接得出，不插值、不推算）。
- 【每日动向】**保持原有展示不变**：继续沿用既有的 3 个交易日过滤视图，不新增按钮、不受开关状态影响。已核实它当前确实受该过滤影响（3 日视图 355 行 vs 5 日视图 432 行，差 77 行、涉及 16 个交易日），「保持原样」即保持 3 日过滤结果及其离场标记口径。
- 同步修正页面 `Notice` 与管道 `scope_note` 中关于「标记保留 3 个交易日，之后不再展示」的表述，改为分 Tab 说明；仅改文案。

**用户已确认口径（2026-11-14，第二轮修订，覆盖第一轮）**：① 默认隐藏 + 切换按钮；② 统一 5 日、取消 3 日那道线；③ 起算日为 `exit_date`；④ **5 日阈值仅作用于【游资总览】与【个股游资总览】，【每日动向】原本怎么展示就怎么展示**；⑤ 按钮放在【游资总览】与【个股游资总览】两个 Tab。

**撤销第一版产物中的未经确认表述**：第一版把「统一」擅自限定为「仅个股游资总览」，并写入「游资总览 / 每日动向维持 3 日」「跨 Tab 差异是本次确认的既定结果」——这两句均无用户确认，本版全部作废。相应地，第一版 `design.md` 决策 1 所述「3 日裁剪会先删掉第 4~5 日配对」的前提也不成立：新的 5 日视图直接从原始产物构建，不经过任何 3 日视图；3 日视图仅保留给每日动向。

**待确认的设计假设**（不影响验收口径，实施时可调整）：两个 Tab 的按钮共享同一个开关状态，即在任一 Tab 点开后，切到另一个 Tab 也保持开启态；【每日动向】始终不消费该状态。

**Non-Goals（明确不做）**：不改 `SILENT_PROBABLE=4` / `SILENT_FORCED=8` / `HEAVY_SELL_RATIO=0.8` / `TURNOVER_COVER_X=5` 等判定参数；不改 `_compute_positions()` 状态机；不改 `data/lhb-traders.json` 的 schema 与任何数值；不新增派生指标、分位、环比或前端推算量；不持久化按钮状态（页面内 state，刷新即复位）；不改服务端 `/api/lhb/*` 契约；不动顶部/底部信号、板块趋势及其他页面。

## Capabilities

### New Capabilities

- `lhb-traders-view`: 【龙虎榜知名游资】页的离场配对展示时效契约，覆盖【游资总览】与【个股游资总览】的 5 交易日保留/默认隐藏规则与共用切换按钮，以及【每日动向】保持既有 3 交易日展示口径不变的边界约束。

## Impact

- **前端**：`signal-hub-web/src/pages/LhbTraders.tsx`（过滤纯函数参数化、页面级开关 state、两个 Tab 各渲染一个按钮）、新增一个可单测的纯函数模块、新增一个 `node:test` 测试文件。视图分割线为「5 日 + 可回显：游资总览/个股游资总览」与「3 日 + 不回显：每日动向（原样）」。
- **管道文案**：`pipeline/lhb_traders.py` 的 `EXIT_MARK_DAYS` 注释与 `scope_note` 文案（纯文本）；产物 `data/lhb-traders.json` 的 `scope_note` 用定点替换同步，**本期不手动重跑产物、不改其中数据**。
- **API / 依赖**：无。`server/lhb.py` 已透传 `scope_note`、`trading_dates`、`traders[].positions`，前端所需字段全部现成，无新增端点、无新增依赖。
- **信号链路**：无影响。`pipeline/lhb_traders.py` 文件头明确限定龙虎榜「只做事后统计与展示，不得被任何顶部/底部信号、板块趋势或候选状态计算读取」；本变更亦不触碰三层确认机制、复权方式或任何准确率口径。
- **风险**：阈值与起算日均为纯展示判定，不含未来函数（`exit_date` 与 `as_of` 均 ≤ `as_of`，日期轴取自产物 `trading_dates`）。主要回归风险有两处：一是「展示什么就统计什么」的既有约定——开关会同步改变两个 Tab 的卡片统计与个股合计金额；二是每日动向必须保持 3 日视图且与改动前逐日一致，须在测试中用基线断言锁死。
