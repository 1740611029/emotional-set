# Spec Delta

## Purpose

提供板块维度的趋势浏览能力：让用户按申万一级/二级板块查看走势曲线与当前四态（多头 / 退潮 / 空头 / 反转）、持续天数与方向强度，并能读懂强度数值的含义与算法构成，同时清楚区分一级与二级板块的独立判定结果及两者的差异。

## ADDED Requirements

### Requirement: 板块层级组织与导航

页面 MUST 以申万一级板块为顶层单元展示，选中某个一级板块后 MUST 展示其全部二级细分板块。每个二级板块 MUST 只归属一个一级板块，且 MUST 能通过父级名称定位。

#### Scenario: 默认展示一级板块全集
- **WHEN** 用户进入板块趋势页
- **THEN** 页面 MUST 列出快照中全部一级板块，并 MUST 默认选中其中一个（优先选中强度最高者），右侧展示其详情

#### Scenario: 展开二级板块
- **WHEN** 用户选中某一级板块
- **THEN** 页面 MUST 展示该板块下全部二级细分板块及其独立状态与强度，且 MUST NOT 混入其他一级板块的子板块

#### Scenario: 板块无子板块
- **WHEN** 某一级板块在数据中不存在二级板块
- **THEN** 页面 MUST 显示明确的空状态文案，MUST NOT 留白或隐藏该区域

### Requirement: 四态语义与标签固定

页面 MUST 使用固定的四态取值与中文标签：`bull` → 多头、`warn` → 退潮、`bear` → 空头、`rise` → 反转。四态 MUST 各自对应可区分的视觉标识，且 MUST NOT 使用"买入""卖出"等交易指令性措辞。

#### Scenario: 状态标签映射
- **WHEN** 渲染任一板块的状态
- **THEN** 标签 MUST 为"多头 / 退潮 / 空头 / 反转"之一，且同一状态在列表、详情、图例中的标签与配色 MUST 一致

#### Scenario: 未分类状态
- **WHEN** 某板块的 `state` 为空或为 `unclassified`
- **THEN** 页面 MUST 显示"数据不足/未分类"，MUST NOT 赋予四态之一的颜色，且 MUST NOT 计入任何四态的筛选结果

### Requirement: 二级板块独立判定与父级差异提示

页面 MUST 把二级板块的状态呈现为**其自身日线的独立判定结果**。当二级板块状态与所属一级板块不一致时，页面 MUST 显式提示差异（指出父级状态），且 MUST NOT 用父级状态覆盖或弱化子级状态。

#### Scenario: 状态一致
- **WHEN** 某二级板块状态与父级相同
- **THEN** 页面 MUST 正常展示其状态，且 MUST NOT 显示差异提示

#### Scenario: 状态不一致
- **WHEN** 某二级板块状态与父级不同
- **THEN** 该行 MUST 显示"与所属一级板块（<父级状态>）不一致"提示，且其状态标签 MUST 使用自身状态

#### Scenario: 一级板块内出现多种状态
- **WHEN** 某一级板块的子板块存在两种以上状态
- **THEN** 页面 MUST 在父级详情区显示子板块状态分布摘要，便于识别内部分化

### Requirement: 强度数值语义与构成解释

页面 MUST 把方向强度呈现为 0–100 的"当前状态方向的强度"，并 MUST 提供可展开的解释面板，说明：50 为中性、接近 0 或 100 为极端；`bull` / `rise` 状态未取反，`bear` / `warn` 状态已取反（数值越高表示该方向越强）；强度由"近 20 日区间位置分"与"相对 60 日均线偏离分"两项构成。

#### Scenario: 数值口径可见
- **WHEN** 用户查看任一板块的强度
- **THEN** 页面 MUST 展示保留一位小数的数值，并 MUST 提供进入解释面板的入口，说明 0–100、50 中性与取反规则

#### Scenario: 构成分解可复算
- **WHEN** 用户展开强度解释面板
- **THEN** 面板 MUST 显示该板块的 `range_position` 与 `ma_score` 两项构成分，并按 `strength_basis` 给出可复算的算式（`directional` 为两项均值，`inverted` 为 `100 - 两项均值`，`neutral` 为固定 50）

#### Scenario: 空头与退潮的语义说明
- **WHEN** 某板块状态为 `bear` 或 `warn`
- **THEN** 解释面板 MUST 明确说明该数值为取反后的"空头方向强度"，数值越高表示下跌方向越强，MUST NOT 被解读为看涨信号

#### Scenario: 跨状态不可比提示
- **WHEN** 页面同时展示多种状态的强度
- **THEN** 页面 MUST 提示"强度只在同一状态内可比，跨状态数值不可直接比较"

#### Scenario: 数据异常
- **WHEN** 某板块 `data_anomaly` 为真（近 20 日高低价相同）
- **THEN** 页面 MUST 标注强度为固定中性值 50，并 MUST NOT 将其作为强度排序的有效依据

### Requirement: 筛选、排序与检索

页面 MUST 支持按四态筛选、按强度排序，并支持按板块名称或代码检索。筛选与排序 MUST 实时作用于列表，且 MUST 展示当前筛选结果的数量。

#### Scenario: 按状态筛选
- **WHEN** 用户选择"多头"筛选
- **THEN** 列表 MUST 只保留 `state` 为 `bull` 的板块，并显示命中数量；选中项被筛除时 MUST 自动切换到列表首项或显示未选中态

#### Scenario: 按强度排序
- **WHEN** 用户选择按强度排序且列表包含多种状态
- **THEN** 列表 MUST 按 `strength` 降序排列，`strength` 为空的板块 MUST 排在末尾，并 MUST 同时显示跨状态不可比提示

#### Scenario: 检索无结果
- **WHEN** 用户输入的检索词不匹配任何板块
- **THEN** 页面 MUST 显示"无匹配板块"空状态，MUST NOT 显示空白列表

### Requirement: 板块走势图

页面 MUST 展示选中板块最近一段交易日的收盘走势，并 MUST 在同一图表中标注该区间内每日的四态变化。图表 MUST 支持时间范围切换（60 / 120 / 250 个交易日），MUST 支持悬停查看单日日期、收盘价与当日状态。

#### Scenario: 走势与状态带同时呈现
- **WHEN** 用户选中某板块
- **THEN** 图表 MUST 展示该板块收盘序列，并 MUST 以背景色带或等效方式标出区间内每日四态，且图例 MUST 与状态标签一致

#### Scenario: 时间范围切换
- **WHEN** 用户切换时间范围
- **THEN** 图表 MUST 按所选交易日数量重绘，且 MUST NOT 触发整页重新加载

#### Scenario: 悬停读数
- **WHEN** 用户将指针移动到图表某一交易日
- **THEN** 图表 MUST 显示该日日期、收盘价与当日状态

#### Scenario: 历史长度不足
- **WHEN** 选中板块可用历史少于所选时间范围
- **THEN** 图表 MUST 按实际可用长度绘制并提示实际覆盖区间，MUST NOT 插值或补造缺失交易日

#### Scenario: 状态序列缺失
- **WHEN** 某板块无状态序列（历史不足 60 日或数据异常）
- **THEN** 图表 MUST 仍绘制可用收盘序列，并 MUST NOT 绘制状态色带

### Requirement: 状态摘要与数据时点

详情区 MUST 展示选中板块的当前状态、状态持续天数、方向强度数值、强度是否取反与数据所属交易日。MUST NOT 展示无法由数据支撑的推断值。

#### Scenario: 摘要字段完整
- **WHEN** 用户查看任一板块详情
- **THEN** 摘要 MUST 包含状态标签、持续天数、强度值（保留一位小数）、强度口径（取反/未取反）与 `as_of`

#### Scenario: 数据滞后提示
- **WHEN** 某板块 `data_lag` 为真
- **THEN** 页面 MUST 显示该板块的数据日期早于 `as_of` 的提示

### Requirement: 二级板块独立状态的历史评估披露

页面 MUST 披露二级板块独立四态的历史方向评估结果，包含每个状态的 10 日与 20 日胜率、已判定样本数、统计分段与 Wilson 区间，并 MUST 明确说明该评估在研究与验证两段之间不稳定、仅作描述性分类。

#### Scenario: 评估可见
- **WHEN** 用户查看二级板块区域
- **THEN** 页面 MUST 提供评估结果的可见入口，且 MUST 同时展示胜率与已判定样本数，MUST NOT 只展示百分比

#### Scenario: 稳定性提示
- **WHEN** 展示二级板块评估
- **THEN** 页面 MUST 显示"研究段与验证段结果不一致、无稳定方向优势"的提示

### Requirement: 描述性定位与风险提示

四态 MUST 呈现为描述性分类，MUST NOT 呈现为买入/卖出建议或预期收益。页面 MUST 展示数据自带的说明（板块趋势为描述性分类、方向胜率不代表交易收益），且 MUST NOT 省略该提示。

#### Scenario: 说明可见
- **WHEN** 用户查看板块趋势页
- **THEN** 页面 MUST 可见地展示"描述性分类、不代表交易收益"的说明文案

#### Scenario: 无交易指令
- **WHEN** 审查页面文案与交互
- **THEN** MUST NOT 出现"买入""卖出""建仓""目标价"等指令性措辞

### Requirement: 加载、失败与陈旧降级

页面 MUST 复用站点统一数据层的加载、失败与陈旧降级行为：首次加载显示加载态；请求失败时保留上一次成功数据并提示失败原因；数据陈旧时显示陈旧提示与最近成功时间。MUST NOT 回退到编造的示例数值。

#### Scenario: 首次加载
- **WHEN** 用户首次打开板块趋势页且数据尚未返回
- **THEN** 页面 MUST 显示加载态，MUST NOT 显示任何数值

#### Scenario: 请求失败保留旧数据
- **WHEN** 数据请求失败且存在上一次成功数据
- **THEN** 页面 MUST 继续展示旧数据并显示失败提示与最近成功时间
