# Spec Delta

## Purpose

定义指数顶底信号的评价与统计契约，确保任何对外展示的准确率都带明确判定口径、样本数量与统计区间，并能与新算法之外的历史口径并列对照。

## ADDED Requirements

### Requirement: 主胜率判定口径固定

主胜率 MUST 沿用"后续出现均线反转"判定：底部信号成功当且仅当在该信号之后、下一个反向信号之前出现首次均线反转；顶部信号同理取反向。该口径 MUST NOT 在未单独评审的情况下更换，任何更换 MUST 视为口径变更并同步更新算法版本与说明。

#### Scenario: 底部成功判定
- **WHEN** 某 `bottom` 信号之后、下一个 `top` 信号之前出现首次均线反转
- **THEN** 该信号 MUST 记为 `success`，并记录反转发生的交易日与间隔天数

#### Scenario: 被反向信号截断判失败
- **WHEN** 某 `bottom` 信号之后先出现下一个 `top` 信号，且期间未出现均线反转
- **THEN** 该信号 MUST 记为 `failure`，确认日 MUST 记为反向信号日

### Requirement: 准确率必须带样本量与区间

任何对外展示的准确率 MUST 同时给出已判定样本数、成功数、失败数、未决数、统计起止日期与 95% 置信区间。已判定样本少于 30 时 MUST 输出小样本提示，MUST NOT 仅以百分比呈现。

#### Scenario: 小样本提示
- **WHEN** 某指数某方向的已判定样本为 12 个
- **THEN** 输出 MUST 包含样本数 12、Wilson 区间与"样本量较小，仅供参考"提示

#### Scenario: 未决不计入分母
- **WHEN** 某信号在统计区间结束前既未反转也未遇到反向信号
- **THEN** 该信号 MUST 记为 `pending`，MUST NOT 进入胜率分母

### Requirement: 分段评价

评价 MUST 至少分为研究段与验证段两个区间，两段 MUST 分别给出准确率与样本量。研究段 MUST 截止于固定日期，MUST NOT 随数据更新而延长；验证段 MUST 从研究段结束次日起算。

#### Scenario: 两段分别报告
- **WHEN** 生成评价结果
- **THEN** 输出 MUST 包含 `research` 与 `exploratory_validation` 两段的起止日期、样本数与成功率

#### Scenario: 研究段不随数据延长
- **WHEN** 原始行情更新到更晚的交易日
- **THEN** 研究段的结束日期 MUST 保持不变

### Requirement: 诊断指标与主口径分离

系统 SHALL 额外输出前瞻收益与最大不利偏移作为诊断指标，包含信号后 5/10/20 个交易日收益与区间内最大回撤。诊断指标 MUST NOT 参与主胜率计算，MUST NOT 改变主胜率的分子或分母。

#### Scenario: 诊断指标单独列示
- **WHEN** 展示某信号的评价结果
- **THEN** 主胜率与诊断指标 MUST 分属不同字段，且诊断字段 MUST 明确标注"不参与胜率计算"

#### Scenario: 诊断指标不改变主口径
- **WHEN** 新增或修改诊断指标的计算方式
- **THEN** 主胜率的数值 MUST 保持不变

### Requirement: 基准对照

评价 MUST 提供基准对照：在同期全部交易日中随机取相同数量的日期，按同一主胜率口径计算基准成功率。信号成功率 MUST 与基准成功率并列展示，以便判断信号是否真正优于"任意一天"。

#### Scenario: 基准率并列展示
- **WHEN** 输出某指数某方向的准确率
- **THEN** 输出 MUST 同时包含信号成功率与同期基准成功率，以及两者差值

### Requirement: 跨指数合并统计

当单指数单方向样本不足 30 时，系统 MUST 提供跨指数合并统计，并 MUST 同时给出各指数分项，MUST NOT 只展示合并值而隐藏分项差异。

#### Scenario: 合并值附带分项
- **WHEN** 7 个指数合并后的样本为 45 个
- **THEN** 输出 MUST 同时包含合并样本数、合并成功率与 7 个指数各自的分项样本数与成功率
