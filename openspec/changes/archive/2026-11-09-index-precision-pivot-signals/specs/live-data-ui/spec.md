# Spec Delta

## MODIFIED Requirements

### Requirement: 准确率展示必须带样本量

页面展示任何准确率时 MUST 同时展示触发次数、已判定样本数、未决数与统计区间；样本数不足时 MUST 显示小样本提示。MUST NOT 仅展示单一百分比，MUST NOT 只展示较宽松的一种口径。多持有期矩阵的每一格 MUST 独立满足上述要求，MUST NOT 用其他持有期的样本量代替。个位数样本 MUST 如实显示 `n=…`、Wilson 95% 区间与统计区间，MUST NOT 省略样本量。

#### Scenario: 准确率卡片
- **WHEN** 页面展示某指数的准确率
- **THEN** 卡片 MUST 同时包含触发次数、已判定样本数、未决数、统计起止区间、方向正确率与有效幅度率；当已判定样本数少于 30 时 MUST 显示小样本提示

#### Scenario: 逐格不复用样本量
- **WHEN** 30 日持有期格因持有期未满未决数较多
- **THEN** 该格 MUST 显示自身的触发次数、已判定样本数与未决数，MUST NOT 复制 5 日格的样本量

## ADDED Requirements

### Requirement: 指标总览多持有期矩阵卡片

【指标总览】MUST 以多持有期矩阵替换单一「已判定胜率」卡片：按 5 / 10 / 20 / 30 交易日持有期 × `bottom` / `top` 方向呈现，并可按研究段 / 独立验证段切换。每格 MUST 同时给出方向正确率、有效幅度率、触发次数（`n=…`）、已判定样本数、未决数、Wilson 区间与平均最大不利偏移。MUST NOT 再以单一百分比（如 97.4%）作为唯一准确率呈现。矩阵 MUST 遵循项目既有清新淡色风格（主色 `#3a9a6a`，辅色天蓝 / 薄荷绿 / 珊瑚橙）与既有字体、卡片、栅格规范，MUST NOT 引入第二套视觉语言。无数据的格 MUST 显示 `--` 或「暂无样本」，MUST NOT 显示 0% 或补造数值。页面 MUST 用业务语言解释浮亏约束（例如「信号后中途最多允许浮亏 5%，超出即判失败」）。

#### Scenario: 矩阵替换单一胜率
- **WHEN** 用户打开【指标总览】
- **THEN** 页面 MUST 呈现 4 持有期 × 2 方向的矩阵，MUST NOT 出现不带触发次数的单一「已判定胜率」百分比

#### Scenario: 每格字段齐全
- **WHEN** 查看 20 日 / `bottom` 格
- **THEN** 该格 MUST 显示方向正确率、有效幅度率、`n=…`、已判定样本数、未决数、Wilson 区间与平均最大不利偏移

#### Scenario: 无样本不补造
- **WHEN** 某格没有任何已判定样本
- **THEN** 该格 MUST 显示 `--` 或「暂无样本」，MUST NOT 显示 0% 或任何推测值

#### Scenario: 浮亏约束通俗说明
- **WHEN** 页面首次展示浮亏硬约束
- **THEN** 页面 MUST 显示通俗解释与示例（如「3000 点信号，中途最低不跌破 2850 点」），MUST NOT 只显示技术字段名

### Requirement: 统计覆盖范围标注与拐点对照

页面 MUST 明确标注准确率统计所覆盖的标的清单与标的数，并 MUST 与【指标总览】展示的 7 张指数图卡范围可区分，MUST NOT 让读者误以为图示信号数量与统计样本数量相同。折线图 MUST 在保留确认日 marker 的同时，以视觉上可区分的样式标注拐点基准日与拐点自然确认日，MUST NOT 把拐点基准日误呈现为信号发出日。图例 MUST 说明三者的区别，MUST NOT 省略。切换页面 MUST 复用同一快照，MUST NOT 触发重复请求。

#### Scenario: 统计范围可区分
- **WHEN** 准确率矩阵合并了扩展标的池
- **THEN** 页面 MUST 显示「统计覆盖 N 个标的」并列出清单，且与 7 张图卡的标题范围明确区分

#### Scenario: 拐点日与信号日可区分
- **WHEN** 折线图同时呈现拐点基准日、自然确认日与信号确认日
- **THEN** 三者 MUST 使用不同标记样式并在图例中说明，MUST NOT 用同一 marker 样式

#### Scenario: 不误报为信号发出日
- **WHEN** 用户 hover 拐点基准日标记
- **THEN** 提示 MUST 说明这是事后标注的拐点基准，MUST NOT 表述为「信号发出日」
