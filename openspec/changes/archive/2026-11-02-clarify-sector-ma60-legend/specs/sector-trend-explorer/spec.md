# Spec Delta

## MODIFIED Requirements

### Requirement: 板块走势图

页面 MUST 展示选中板块最近一段交易日的收盘走势，并 MUST 在同一图表中标注该区间内每日的四态变化。图表 MUST 支持时间范围切换（60 / 120 / 250 个交易日），MUST 支持悬停查看单日日期、收盘价与当日状态。图表 MUST 提供可见图例，至少包含“收盘”和“MA60（60日均线）”；MA60 图例 MUST 对应蓝色虚线，并明确表示最近 60 个交易日收盘价的简单算术平均值，MUST NOT 被表述为强度或交易信号。

#### Scenario: 走势与状态带同时呈现

- **WHEN** 用户选中某板块
- **THEN** 图表 MUST 展示该板块收盘序列，并 MUST 以背景色带或等效方式标出区间内每日四态，且图例 MUST 与状态标签一致

#### Scenario: MA60 图例含义明确

- **WHEN** 用户查看任一 60 / 120 / 250 日板块走势图
- **THEN** 可见图例 MUST 将蓝色虚线标为“MA60（60日均线）”，且 MUST 同时保留“收盘”图例，使用户无需查看外部文档即可区分价格线与均线

#### Scenario: 图例不遮挡图表内容

- **WHEN** 图表在当前页面尺寸下渲染或调整尺寸
- **THEN** 图例 MUST 位于图表的独立布局区域内，MUST NOT 遮挡收盘价、MA60、坐标读数或时间范围操作

#### Scenario: MA60 历史窗口不足

- **WHEN** 当前序列存在不足 60 个有效收盘价的区间
- **THEN** 对应区间 MUST 继续保持 MA60 无数值，MUST NOT 补造均线点；图例 MUST 保留“MA60（60日均线）”说明

#### Scenario: 时间范围切换

- **WHEN** 用户切换时间范围
- **THEN** 图表 MUST 按所选交易日数量重绘，且 MUST NOT 触发整页重新加载

#### Scenario: 悬停读数

- **WHEN** 用户将指针移动到图表某一交易日
- **THEN** 图表 MUST 显示该日日期、收盘价与当日状态

#### Scenario: 历史长度不足

- **WHEN** 选中板块可用历史少于所选时间范围
- **THEN** 图表 MUST 按实际可用长度绘制并提示实际覆盖区间，MUST NOT 插值或补造缺失交易日

#### Scenario: 状态序列缺失

- **WHEN** 某板块无状态序列（历史不足 60 日或数据异常）
- **THEN** 图表 MUST 仍绘制可用收盘序列，并 MUST NOT 绘制状态色带
