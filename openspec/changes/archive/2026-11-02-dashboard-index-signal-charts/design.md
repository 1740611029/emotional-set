# Design

## Context

前端已经有统一的 30 秒快照数据层；快照中每个指数项都包含完整 `history`、已确认 `signals` 与当前候选 `candidates`，因此本次是纯前端信息呈现改造。ECharts 已用于现有机构持仓与板块走势图，`glass-card` 与品牌色彩体系也已建立。现有通配路由会把未知路径重定向到 `/`，可直接承担 `/indices` 的旧地址迁移。

## Goals / Non-Goals

**Goals:**

- 【指标总览】以七张指数走势图作为主内容，直接展示信号与行情的对应位置。
- 七张图共用时间范围选择，默认“近一年”，支持用户要求的七个选项。
- 已确认顶部/底部信号与当前待确认候选在方向、状态和确认进度上都可区分。
- 保留盘中临时态、加载、失败、陈旧与空数据提示，保持统一数据源和 30 秒刷新行为。

**Non-Goals:**

- 不修改指数信号计算、候选确认算法、准确率统计或任何后端产物。
- 不新增指数历史接口；“全部”仅指当前快照已包含的历史。
- 不展示历史过期候选，也不把候选标记解释为交易建议。
- 不改动板块趋势和机构持仓页面。

## Decisions

### D1：七张独立图卡，而不是单图切换或七线叠加

按用户确认，桌面端以两列网格同时渲染 7 张图，第 7 张位于末行；小屏降为单列。每张图使用自身指数点位，避免七条曲线量纲差异导致互相挤压，同时保留横向比较能力。

- 备选：单图加指数切换——单图可读性更好，但不能一眼比较 7 个指数。
- 备选：七条线叠加——需要归一化，削弱真实点位关系，且标记会很拥挤。

### D2：在前端对现有快照历史截断，不新增接口

图表直接使用快照中的 `history`、`signals` 与 `candidates`。时间范围变化只执行本地切片和图表刷新，不请求新数据，也不改变数据层。

- 备选：为每个指数请求历史接口——能提供更大历史，但首页会引入额外请求，增加数据时点不一致和请求风暴风险；不符合本次“沿用现有快照”的边界。

### D3：时间范围按交易日数量映射

范围常量建议映射为：近一个月 22、近三个月 66、近半年 126、近一年 252、近两年 504、近三年 756、全部不限。这样与 A 股实际交易日对齐，也与项目现有板块历史范围习惯一致；“全部”使用当前快照的完整序列并显示真实起止日期与点数。

- 备选：按自然日日期截断——节假日期间容易出现精确月份折算和月末边界差异；按交易日更稳定、可测试。

### D4：用折线图的 markPoint 分层渲染信号

每条折线保留一条价格序列，并叠加独立的已确认信号与候选信号 markPoint 集合：

- 已确认底部：实心向上三角，使用薄荷绿；已确认顶部：实心向下三角，使用珊瑚橙。
- 候选信号：同方向颜色的空心三角，尺寸略小，文案和 tooltip 始终标注“待确认/未确认”。
- tooltip 对两个集合分别输出状态、日期、方向、触发价；候选另输出价格、动量、量能与已等待交易日数。

- 备选：另建 Scatter 序列——能把状态完全拆成独立图例，但增加隐藏序列、坐标映射与 tooltip 聚合复杂度；markPoint 与价格坐标关系更直接。

### D5：保留辅助区，替换重复统计区

顶部确认数、候选数、准确率和最活跃指数四个摘要卡片继续保留；“最新信号状态”和“待确认候选”两个列表保留，便于快速读取详情；原“信号分布”和“近 30 日信号趋势”两个统计块删除，由七图主区承担横向浏览。页面顺序为摘要卡片 → 七图主区 → 最新信号 → 待确认候选，图表仍是第一屏后的核心内容。

- 备选：全部删除只留图表——页面更简洁，但会丢掉既有候选确认进度列表和新信号速览。
- 备选：全部保留——信号数量统计与新图表重复，进一步加重页面长度。

### D6：通过删除路由和导航项完成页面移除

删除 `Indices` 路由、`Sidebar` 中的【宽基指数】项及对应页面文件；通配重定向会继续把 `/indices` 带到首页。无需新增专门 alias，因为现有路由已经覆盖旧地址。

## Risks / Trade-offs

- 七张 ECharts 同时刷新可能增加短时间渲染开销 → 全部数据合计约数千点，量级可控；图表关闭动画、使用 `ResizeObserver` 复用现有模式，并将价格切片与 marker 生成保持为纯计算。
- 密集信号在窄图中可能重叠 → 小图只展示方向标记，详细日期、状态、触发价放在 tooltip；桌面图卡提供足够高度，隐藏部分轴标签而不是缩小到不可读。
- 候选与已确认信号可能出现在相近日期 → 两类 marker 分别建模并在 tooltip 明确状态，避免把候选误读为已确认。
- 盘中快照每 30 秒更新导致图表重绘 → 继续沿用统一数据层和 React memo，只在快照对象变化时更新 option；不额外请求。
- “近三年”以外的“全部”历史口径与用户直觉可能有差异 → 图表明确显示真实覆盖起止日期与交易日数量，不声称超出快照历史。
- 旧 `/indices` 地址不再具有独立含义 → 自动重定向到首页，保留直达链接的可用性；不保留重复入口。

## Migration Plan

1. 新增时间范围、历史切片和信号 marker 映射的纯函数与测试。
2. 新增可复用指数信号图组件，并接入【指标总览】；先保留旧统计块直至新图通过构建和交互检查。
3. 删除旧统计块，再移除【宽基指数】导航项、路由与页面文件。
4. 运行单测、`tsc`、前端构建及旧地址刷新检查。
5. 回滚策略：恢复被删除页面与导航、还原 Dashboard 与图表组件；本改动无数据库或后端数据迁移，回滚不会修改信号产物。
