# Proposal

## Why

当前板块强度在空头/退潮状态下取反，用户需要额外理解“数值越高代表下跌越强”，阅读不直观；点击二级板块又会替换整个右侧详情，容易丢失一级板块的浏览上下文。本次改动让强度直接用正负表达方向，并用弹窗承载二级板块详情。

## What Changes

- **BREAKING**：板块 `strength` 从 0–100 的“当前状态方向强度”改为 -50–+50 的“有向强度”：两项原始构成分均值减 50，正值偏强、负值偏弱、0 为中性；不再按 `bull` / `warn` / `bear` / `rise` 取反。
- 强度构成 `range_position` 与 `ma_score` 仍保持 0–100，零通道异常的中性强度由 50 改为 0；四态判据、状态持续天数、历史收盘序列与历史评估算法不变。
- 同步更新强度解释、摘要、排序提示、数据 Schema 与相关测试，使界面、产物和校验公式使用同一套有向强度口径。
- 点击二级细分板块时，在保留当前一级板块详情与二级列表的页面上打开详情弹窗；弹窗展示该二级板块自身的状态、父级差异、有向强度、数据日期与可切换 60 / 120 / 250 日的收盘走势。
- 二级弹窗支持关闭及加载、失败、历史不足等状态，不将二级板块数据替换为父级数据，不引入交易建议。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `sector-trend-explorer`: 修改强度数值语义、解释与排序提示，并将二级板块详情从替换主详情区改为弹窗交互。
- `market-data-pipeline`: 修改板块强度取值范围、计算公式、零通道中性值与产物校验契约；四态算法及历史评估不变。

## Impact

- 影响 `pipeline/confirmed_sector_trends.py`、`pipeline/schemas.py` 及板块趋势相关流水线测试。
- 影响板块快照与历史接口返回的 `strength` / `strength_basis` 数值语义，但不改变接口路径和字段结构。
- 影响 `signal-hub-web` 的板块页面、强度解释组件、状态计算工具与二级详情弹窗；需要补充弹窗交互测试。
- 需要更新根 `README.md` 的强度说明，并保留改动前后产物对照；旧版 0–100 强度数据不能与新版有向强度混用。
