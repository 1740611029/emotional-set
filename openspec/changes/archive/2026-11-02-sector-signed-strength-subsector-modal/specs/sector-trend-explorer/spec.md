# Spec Delta

## ADDED Requirements

### Requirement: 二级板块详情弹窗

点击二级细分板块时，页面 MUST 在当前一级板块页面上打开该二级板块的详情弹窗，MUST NOT 用二级板块替换一级板块主详情或隐藏二级细分列表。弹窗 MUST 展示二级板块自身的独立状态、与父级状态的差异、有向强度、持续天数、数据日期及收盘走势图，并 MUST 支持 60 / 120 / 250 个交易日范围切换。

#### Scenario: 打开二级板块详情

- **WHEN** 用户点击二级细分板块列表中的某个板块
- **THEN** 页面 MUST 打开该板块的详情弹窗，背景中的一级板块主详情与二级列表 MUST 保持原选中状态

#### Scenario: 弹窗使用二级板块自身数据

- **WHEN** 二级板块详情弹窗加载完成
- **THEN** 弹窗中的状态、强度、日期与历史序列 MUST 来自被点击的二级板块，MUST NOT 回退或替换为父级板块数据

#### Scenario: 关闭弹窗恢复浏览

- **WHEN** 用户通过关闭按钮或 Escape 键关闭弹窗
- **THEN** 页面 MUST 返回打开前的一级板块浏览上下文，且 MUST NOT 重新选择其他一级板块

#### Scenario: 弹窗历史加载中或失败

- **WHEN** 二级板块历史数据尚未返回或请求失败
- **THEN** 弹窗 MUST 显示对应加载或失败状态，MUST NOT 展示父级序列或编造的示例数值

#### Scenario: 弹窗内切换时间范围

- **WHEN** 用户在弹窗内切换 60 / 120 / 250 日范围
- **THEN** 走势图 MUST 按该二级板块自身的历史数据重绘，且 MUST NOT 关闭弹窗或刷新整页

## MODIFIED Requirements

### Requirement: 强度数值语义与构成解释

页面 MUST 把方向强度呈现为 -50–+50 的“有向强度”，并 MUST 提供可展开的解释面板，说明：0 为中性，正值表示相对偏强，负值表示相对偏弱，绝对值越大表示偏离中性越远；所有状态 MUST 使用同一公式，MUST NOT 因 `bull` / `rise` / `bear` / `warn` 状态而取反。强度由“近 20 日区间位置分”与“相对 60 日均线偏离分”两项构成，两项原始构成分仍为 0–100。

#### Scenario: 数值口径可见

- **WHEN** 用户查看任一板块的强度
- **THEN** 页面 MUST 展示保留一位小数的有向强度，并 MUST 提供进入解释面板的入口，说明 -50–+50、0 中性与正负方向含义

#### Scenario: 构成分解可复算

- **WHEN** 用户展开强度解释面板
- **THEN** 面板 MUST 显示该板块的 `range_position` 与 `ma_score` 两项构成分，并给出可复算算式 `strength = (range_position + ma_score) / 2 - 50`；零通道异常 MUST 单独说明固定为 0

#### Scenario: 空头与退潮的语义说明

- **WHEN** 某板块状态为 `bear` 或 `warn`
- **THEN** 页面 MUST 直接展示按统一公式计算的有向强度，MUST NOT 再显示“取反”“空头方向强度”或“数值越高表示下跌越强”的旧口径说明

#### Scenario: 跨状态不可比提示

- **WHEN** 页面同时展示多种状态的强度
- **THEN** 页面 MUST 按同一正负方向口径展示，MUST NOT 显示“强度只在同一状态内可比，跨状态数值不可直接比较”的旧提示

#### Scenario: 数据异常

- **WHEN** 某板块 `data_anomaly` 为真（近 20 日高低价相同）
- **THEN** 页面 MUST 标注强度为固定中性值 0，并 MUST NOT 将其作为强度排序的有效依据

### Requirement: 筛选、排序与检索

页面 MUST 支持按四态筛选、按有向强度排序，并支持按板块名称或代码检索。筛选与排序 MUST 实时作用于列表，且 MUST 展示当前筛选结果的数量。

#### Scenario: 按状态筛选

- **WHEN** 用户选择“多头”筛选
- **THEN** 列表 MUST 只保留 `state` 为 `bull` 的板块，并显示命中数量；选中项被筛除时 MUST 自动切换到列表首项或显示未选中态

#### Scenario: 按强度排序

- **WHEN** 用户选择按强度排序且列表包含多种状态
- **THEN** 列表 MUST 按有向 `strength` 数值降序排列，`strength` 为空或数据异常的板块 MUST 排在末尾，且 MUST NOT 使用绝对值或按状态取反后的数值排序

#### Scenario: 检索无结果

- **WHEN** 用户输入的检索词不匹配任何板块
- **THEN** 页面 MUST 显示“无匹配板块”空状态，MUST NOT 显示空白列表

### Requirement: 状态摘要与数据时点

详情区 MUST 展示选中板块的当前状态、状态持续天数、有向强度数值、统一强度口径与数据所属交易日。MUST NOT 展示无法由数据支撑的推断值，也 MUST NOT 再展示强度是否按多空取反。

#### Scenario: 摘要字段完整

- **WHEN** 用户查看任一一级板块详情或二级板块详情弹窗
- **THEN** 摘要 MUST 包含状态标签、持续天数、保留一位小数的有向强度、强度口径（有向/中性）与 `as_of`

#### Scenario: 数据滞后提示

- **WHEN** 某板块 `data_lag` 为真
- **THEN** 页面 MUST 显示该板块的数据日期早于 `as_of` 的提示
