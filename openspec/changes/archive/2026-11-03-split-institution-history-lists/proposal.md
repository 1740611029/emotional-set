# Proposal

## Why

「机构多空单」页面的历史明细目前把国泰君安、中信期货、其他机构三家混排在同一张表里，按日期倒序交替出现，用户想连续追踪某一家机构的持仓变化时，需要在交错行中逐行辨认机构列，翻阅体验差。用户要求把历史明细拆分为三个独立列表分别展示。

## What Changes

- 历史明细区域由「单一混合列表 + 机构下拉筛选」改为「三个独立列表」：分别展示中信期货、国泰君安、其他机构的历史明细
- 三个列表纵向堆叠排列，每张表保留完整的明细列（日期、品种、多单、空单、净持仓、净持仓变化、次日沪深300、关系判定），各自独立分页
- 品种 Tab（四品种汇总 / IF / IC / IH / IM）与日期区间筛选对三个列表同时生效；移除历史明细区域的「机构」下拉筛选（分开展示后冗余）
- 单列表标题处标明机构名称，「其他机构」列表沿用其口径说明（前 20 会员中除国泰君安、中信期货外的合计）
- 不影响数据接口、信号计算、当日快照表、折线图与同向率摘要；纯前端展示层调整

假设（用户未逐项确认，按页面既有约定推定）：

- 三个列表的排列顺序沿用页面既有的固定分组顺序「国泰君安 → 中信期货 → 其他机构」，与当日快照、图例保持一致
- 每张表的列结构与现有历史明细一致；因每张表只含单一机构，「机构」列不再重复展示，改由列表标题承担

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `institution-position-view`: 修改「历史明细列表」需求——由支持机构筛选的单一混合列表，改为按机构拆分的三个独立列表，各自分页，共享品种与日期区间筛选

## Impact

- 前端：`signal-hub-web/src/pages/InstitutionPositions.tsx`（历史明细区域重构）；如表格渲染逻辑复用价值高，可能抽出小组件
- 数据接口 / 后端：无改动（`useInstitutionPositions` 返回结构不变，前端按机构分组渲染）
- 信号与计算逻辑：无影响（本页面为事后对照展示，不参与信号计算）
- 规范：`openspec/specs/institution-position-view/spec.md` 的「历史明细列表」需求及场景更新
