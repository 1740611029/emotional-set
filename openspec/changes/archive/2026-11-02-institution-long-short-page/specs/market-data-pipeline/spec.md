# Spec Delta

## ADDED Requirements

### Requirement: 机构持仓数据源与回溯区间固定

机构持仓数据 MUST 来自中金所每日公布的会员持仓排名（经 akshare `get_cffex_rank_table` 获取），品种范围 MUST 固定为 IF、IC、IH、IM 四个股指期货品种，回溯区间 MUST 固定为最近 3 个自然年内的全部交易日。数据源与区间一旦确定 MUST NOT 在同一产物内混用其他来源或改变起点；确需变更 MUST 视为口径变更并单独评审。

#### Scenario: 抓取范围固定
- **WHEN** 执行机构持仓构建
- **THEN** 产物 MUST 覆盖 IF/IC/IH/IM 四品种，且日期序列 MUST 落在声明的 3 年区间内，首日与末日 MUST 与实际交易日一致

#### Scenario: 数据源失败不静默补值
- **WHEN** 某交易日抓取在重试后仍失败
- **THEN** 该日 MUST 被标记为缺失并保留上一版产物，MUST NOT 以相邻交易日数据填充或估算

### Requirement: 会员别名归一与机构分组互斥

流水线 MUST 在聚合前对会员名称做别名归一（例如"国泰君安"与"国泰君安期货"归为同一会员），并 MUST 保证三家分组（国泰君安、中信期货、其他机构）互斥且并集等于当日参与排名的会员集合。同一会员在同一交易日 MUST NOT 被重复计入多组。

#### Scenario: 别名归一后聚合
- **WHEN** 同一会员在不同品种或不同合约下以不同名称出现
- **THEN** 归一后该会员的持仓 MUST 汇总到同一条记录，且不得出现两条同名分组记录

#### Scenario: 分组守恒
- **WHEN** 对任一交易日、任一品种计算三家分组的多单与空单合计
- **THEN** 三家合计 MUST 等于当日该品种前 20 会员多单与空单的合计，偏差 MUST 为 0

### Requirement: 多空单与净持仓定义

流水线 MUST 将多单定义为会员持买单量之和、空单定义为会员持卖单量之和，净持仓 MUST 定义为 `多单 − 空单`。净持仓变化 MUST 相对该品种的**上一个交易日**计算，MUST NOT 相对上一次抓取日或上一次成功日计算；当上一交易日缺失时该日变化 MUST 输出为空并标记为不可计算。

#### Scenario: 净持仓与变化口径
- **WHEN** 某机构在某日多单为 12000 手、空单为 15000 手
- **THEN** 净持仓 MUST 为 −3000 手，且变化值 MUST 等于当日净持仓减上一交易日净持仓

#### Scenario: 上一交易日缺失
- **WHEN** 某日的前一交易日数据缺失
- **THEN** 该日净持仓变化 MUST 为空值并带有不可计算标记，MUST NOT 以 0 或跨日差值替代

### Requirement: 品种汇总口径

流水线 MUST 同时输出四品种汇总与分品种两套数据。汇总值 MUST 为各品种持仓手数直接相加，且产物 MUST 携带汇总口径说明字段，声明该值未按合约乘数折算为名义金额、不可用于跨品种规模比较。

#### Scenario: 汇总与分品种并存
- **WHEN** 构建任一交易日的机构持仓记录
- **THEN** 产物 MUST 同时包含汇总条目与 IF/IC/IH/IM 四个分品种条目

#### Scenario: 汇总口径说明随产物输出
- **WHEN** 读取产物元信息
- **THEN** MUST 能取得汇总口径说明文本与单位定义，且该说明 MUST 与汇总数值一同返回给前端

### Requirement: 次日同向判定与同向率统计

流水线 MUST 为每个机构 × 品种 × 交易日计算与其**后一个交易日**沪深300 涨跌方向的关系：净持仓变化方向与次日涨跌幅方向相同记为"同向"，相反记为"对冲"，净持仓变化为 0 或次日行情缺失记为"待判定"。同向率 MUST 等于同向天数除以（同向天数 + 对冲天数），且 MUST 同时输出已判定样本数、同向天数、对冲天数、待判定条数与统计起止区间。

#### Scenario: 同向判定
- **WHEN** 某机构当日净持仓增加且次日沪深300 上涨
- **THEN** 该记录关系 MUST 为"同向"

#### Scenario: 对冲判定
- **WHEN** 某机构当日净持仓增加且次日沪深300 下跌
- **THEN** 该记录关系 MUST 为"对冲"

#### Scenario: 待判定处理
- **WHEN** 净持仓变化为 0 或次日沪深300 行情不存在
- **THEN** 该记录关系 MUST 为"待判定"，且 MUST NOT 计入同向率分子或分母

#### Scenario: 同向率带样本量与区间
- **WHEN** 输出任一机构 × 品种的同向率
- **THEN** 同一结构中 MUST 同时包含比率、已判定样本数、同向/对冲/待判定条数与统计起止日期

### Requirement: 事后评估字段与信号计算隔离

次日行情与同向判定结果 MUST 仅用于事后统计与展示，MUST NOT 被任何顶部/底部信号、板块趋势或候选状态计算读取。产物 MUST 以明确的字段命名或标记区分"当日已知"与"事后回填"两类字段，且回填字段在次日数据缺失时 MUST 为空。

#### Scenario: 信号结果不受影响
- **WHEN** 启用机构持仓产物构建后重新生成指数信号与板块趋势
- **THEN** 已确认信号集合与板块状态 MUST 与启用前逐条一致

#### Scenario: 回填字段标记明确
- **WHEN** 审查产物字段
- **THEN** 次日涨跌幅与关系判定字段 MUST 可从命名或元信息识别为事后回填字段，且 MUST 不与当日持仓字段混在同一语义分组

### Requirement: 原始明细缓存与幂等增量抓取

流水线 MUST 将每个交易日的原始会员持仓明细落盘缓存，已缓存且非空的日期 MUST NOT 重复请求远端接口。增量构建 MUST 只补齐缺失日期；对同一日期重复构建 MUST 产出完全相同的结果。非交易日 MUST NOT 产生空记录。

#### Scenario: 增量不重复请求
- **WHEN** 在已有缓存的基础上再次运行构建
- **THEN** 已缓存日期 MUST NOT 发起远端请求，且产物内容 MUST 与上次一致

#### Scenario: 非交易日不产生记录
- **WHEN** 构建区间内包含周末或节假日
- **THEN** 产物日期序列 MUST 只包含实际交易日，MUST NOT 出现空值行

### Requirement: 机构持仓产物契约与校验

产物 MUST 通过结构校验后以原子方式写入；校验失败 MUST 保留上一版文件并输出失败原因。产物 MUST 至少包含：数据所属交易日、生成时间、回溯区间、品种清单、机构分组定义、汇总口径说明、按机构与品种组织的序列，以及同向率摘要。

#### Scenario: 字段完整性
- **WHEN** 构建产物
- **THEN** 产物 MUST 包含交易日、生成时间、区间、品种清单、分组定义、口径说明、序列与同向率摘要，缺失任一字段 MUST 校验失败

#### Scenario: 校验失败保留旧版
- **WHEN** 待写入产物未通过结构校验
- **THEN** 目标文件 MUST 保持原有内容，且 MUST 输出明确失败原因
