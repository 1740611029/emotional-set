# Proposal

## Why

现有六维因子（`position` / `divergence` / `volume` / `volatility` / `trend` / `breadth`）全部由**价量数据**派生，本质仍是"价格自身形状的不同写法"，缺少独立于价格的信息源。这带来一个结构性盲区：在"缩量阴跌 → 急跌 → 无量反弹"这类底部，六个维度会同时给出中庸分数——没有天量、没有背离、波动未放大、宽度未改善——而这恰恰是A股最常见的底部形态之一。顶部同理，估值与杠杆过热在价量维度上往往只表现为"涨得慢"，而非"涨得极端"。

外部世界已有大量成熟体系试图解决这个问题：CNN 恐惧贪婪指数（7 分量等权）、Baker-Wurgler 投资者情绪指数（2006, *Journal of Finance*）、Zweig 宽度推力（breadth thrust）、QVIX 中国波指、两融余额占流通市值比、股债性价比（ERP）、破净率、创新高/新低家数，以及A股民间的"情绪周期"（涨停家数、连板高度、炸板率）。这些体系**从未在本项目的数据口径下被系统评估过**，既不知道它们是否带来增量信息，也不知道它们在A股宽基指数上的历史覆盖是否足以支撑统计结论。

用户明确要求：先做一次全网调研（书籍、学术、卖方研究、民间体系、网络数据），形成候选池与验证协议，**验证通过再谈是否并入生产信号**。本变更即该调研与验证协议的设计契约。

## What Changes

- **新增外部体系证据表**：按"体系 → 代理指标 → 经济含义 → 原始出处 → 数据可得性 → 已知实证结论 → 与本项目六维的相关性假设"七列结构化收录，覆盖四类来源：
  - 经典书籍与交易体系：Howard Marks《周期》的钟摆/市场温度、Stan Weinstein 四阶段、Edwards & Magee 趋势反转、Elder 三重滤网、IBD 追随日（follow-through day）。
  - 学术与卖方研究：Baker-Wurgler 情绪指数、De Bondt-Thaler 过度反应、Zweig 宽度推力、华泰"多维度融合择时"（融资买入额、期权隐含波动率）、中信建投情绪指数择时。
  - 市场数据型指标：QVIX、破净率、新高新低家数、两融余额占流通市值比、融资买入额占比、股债利差、涨停/跌停家数。
  - 民间情绪周期：涨停家数、连板高度、封板率、炸板率、赚钱效应。
- **新增候选因子池与三级分类**：
  - `P0` 数据可回溯 ≥ 5 年、日频、可 point-in-time 复现，可立即进入验证；
  - `P1` 数据存在但历史短（如涨停家数、部分两融明细）或需数据工程（如逐日成分股、破净率口径对齐）；
  - `P2` 不建议采纳（文本情绪、需未来信息、口径不可复现）。
- **新增数据源接入契约（研究态）**：外部数据独立落盘到 `data/raw/external/`，独立 manifest 记录来源、口径、覆盖区间、缺失率；MUST NOT 与现有指数/板块价格口径混用，MUST NOT 进入生产信号计算路径。
- **新增增量信息检验协议**：任何候选因子必须先证明（a）与现有六维的秩相关低于阈值，（b）在**独立于调参区间**的验证段上提升"确认后胜率"或降低误报，（c）样本量与 Wilson 区间同时报告，才有资格进入下一轮。
- **新增调研报告产物**：`data/research/external-signal-survey.json` + 一份面向人的 Markdown 报告，含"哪些体系值得试、哪些明确放弃、放弃理由"。
- **明确不做**：不修改 `swing_indicators.py` / `swing_signal_engine.py`，不改动阈值、确认窗口、波段交替与分级逻辑，不改变现有指数与板块数据口径，不改前端。

## Capabilities

### New Capabilities

- `signal-factor-discovery`: 外部顶底信号体系的调研、证据表结构、候选因子三级分类、数据可得性评级，以及"增量信息检验"的判定协议（相关性门槛、独立验证段、样本量与区间报告要求）。

### Modified Capabilities

- `market-data-pipeline`: 数据源条款由"仅两类价格口径"扩展为"两类价格口径 + 可选的独立辅助口径"。辅助口径 MUST 独立落盘、独立 manifest、独立版本记录，MUST NOT 混入价格口径或参与生产信号计算；任何启用 MUST 单独评审。

## Impact

**受影响代码**

- 新增 `pipeline/external_data.py`：外部指标抓取、缓存、口径校验与 manifest 生成；只读研究用途。
- 新增 `pipeline/factor_survey.py`：候选因子计算、与六维的相关性矩阵、独立区间增量检验。
- 新增 `pipeline/run_signal_survey.py`：一次性产出证据表与检验结果。
- 新增 `pipeline/test_external_factors.py`：口径与未来函数自检（含"打乱未来数据不改变历史得分"的断言）。
- **不改动**：`swing_indicators.py`、`swing_signal_engine.py`、`confirmed_index_signals.py`、`schemas.py`、`build_dashboard.py`、前端。

**依赖**

- 沿用 `akshare`（已在 `requirements.txt`），不新增第三方库。文本情绪类方案不引入 NLP 依赖（已列为 `P2` 放弃）。

**数据与口径影响（对应 AGENTS.md 第 4、5 条，需评审确认）**

1. **新增数据源属口径扩展**：QVIX、破净率、新高新低、两融、股债利差、涨停家数均为新增口径，与现有同花顺指数日线、申万行业日线并列而非替换。
2. **现有信号不受影响**：本变更不进入生产路径，历史信号集合、日期、类型、数量均不变。
3. **point-in-time 风险**：破净率、新高新低等由第三方（乐咕乐股）按当日全市场计算，需核对其是否存在事后修订；核对不通过者降级为 `P1` 或不采纳。
4. **涨停家数历史覆盖短**：东财涨停股池接口仅覆盖近年，且不含已退市标的，按 AGENTS.md 第 8 条只能作辅助证据，不能单独支撑结论。

**准确率与样本影响**

- 本变更不改变生产准确率。若后续采纳候选因子，将触发独立的算法变更与准确率对照，届时按 AGENTS.md 第 7、8、9 条在独立区间验证并保留旧版本。
- 5.8 年 × 7 指数的现有样本对"新增一维是否提升胜率"的检验功效有限；设计上以"跨指数合并样本 + Wilson 区间 + 分年度稳定性"为主口径，单指数单方向结论只作参考。
