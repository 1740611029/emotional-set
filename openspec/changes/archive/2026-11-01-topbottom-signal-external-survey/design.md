# Design

## Context

见 `proposal.md`。设计只补充约束与现状事实：

- 现有因子层 `pipeline/swing_indicators.py` 的输出约定是：每个方向一个 0–1 得分，`rolling_percentile(250, min_periods=60)` 做历史分位，`|2r-1|` 表达"离中位数多远"，六维等权（缺失维按可用权重归一）。新因子若要与六维可比，必须沿用同一套映射约定，否则"加入第 7 维"会变成"改变分数尺度"。
- 现有生产入口是 `pipeline/swing_signal_engine.py` 的 `prepare()` / `swing_details()`，参数集中在 `DEFAULT_PARAMS`。研究流程 MUST 只调用、不修改这些函数与参数。
- 数据现状：`data/raw/indices-ths/`（7 指数，约 6 年）、`data/raw/sectors/{first,second}/`（申万行业）、`data/raw/etf-shares/`、`data/raw/etf-nav/`。尚无任何情绪/资金/估值类数据。
- 生产区间约 2020-10-30 ~ 2026-10-29（约 5.8 年）。任何"训练/验证分段"都受此长度硬约束。
- `akshare` 已在 `requirements.txt`；本机默认 Python 未安装，实际运行环境需确认（见 Open Questions）。

## Goals / Non-Goals

**Goals:**

- 把"外部有哪些顶底/情绪体系"转成一张**可复核、可执行**的证据表，每个条目都能落到具体指标与具体接口。
- 给出一份经过数据核验的候选池：哪些能马上验证、哪些要先做数据工程、哪些明确放弃。
- 定义并**预注册**增量信息检验的门槛（相关性与胜率），避免看到结果再定标准。
- 产出可复现的研究报告，使"是否采纳某个新维度"成为有据可查的决策。

**Non-Goals:**

- 不修改生产信号算法、阈值、确认窗口、波段交替与分级。
- 不接入任何需要爬虫/文本解析的情绪源（新闻、股吧、研报文本）。
- 不追求"最优权重"或参数搜索；本设计刻意限制搜索空间以降低过拟合。
- 不改前端、不改 API、不改生产落盘文件结构。

## Decisions

### D1. 外部数据独立成层，不与价格流水线纠缠

新增 `pipeline/external_data.py`，每个指标一个适配器函数，统一返回 `DataFrame[date, value]` 并写入 `data/raw/external/<indicator>.csv` 与 `data/raw/external/manifest.json`。manifest 每条记录含：接口名、口径说明、抓取时间戳、覆盖区间、行数、缺失率、是否有事后修订标记。

**替代方案**：扩展现有 `fetch_market.py` 增加 `external` 子命令。否决理由——该文件承担生产价格口径，混入辅助口径会让"生产数据从哪来"变得不可审计，且违反 `market-data-pipeline` 的隔离条款。

### D2. 指标对齐不做长前向填充

外部指标按指数交易日历 `reindex`，缺失保留 `NaN`；仅允许**同一交易日内**的缺失用当日可得值补齐，禁止跨日 `ffill` 超过 1 个交易日。

**理由**：情绪类数据停更（如两融某日未披露）若被 `ffill` 成"持平"，会人为制造"情绪稳定"的假信号，且属于隐性未来信息。宁可让该日该维缺失、按可用权重归一，也不补值。

### D3. 新因子沿用六维的映射约定，只增加"维度"不改变"尺度"

每个候选因子先转成 0–1 方向得分：

- 单调型（如 ERP、破净率、两融占比）：`rolling_percentile` 后按方向取 `r` 或 `1-r`；
- 极端型（如 QVIX、换手率）：先分位再 `|2r-1|`，与现有 `volatility` 维同构；
- 比值型（如涨停/跌停家数比）：先取对数比再分位。

**替代方案**：直接用原始值做 z-score。否决理由——不同指标量纲与分布差异过大，z-score 在厚尾分布上不稳定，且无法与六维分数合并。

### D4. 增量检验用"固定权重三档"，不做权重搜索

在现有六维等权分数基础上叠加候选因子，权重只取 `0.10 / 0.15 / 0.20` 三档（对应"轻微倾斜"到"明显倾斜"），全部报告，不选优。若三档结论方向不一致，判为"不稳定"。

叠加形式为**加性倾斜**：`score = base + w × (extra − 0.5)`，其中 0.5 是 `rolling_percentile` 的中性点（历史中位），不是估计参数。选它而非"六维 + 第 7 维求平均"的理由：求平均会让一个恒为常数的无信息因子稀释总分、改变候选集合，从而制造伪效应；加性倾斜对常数因子完全免疫，且在极端处位移与求平均一致（`w=0.15`、`extra=1` 时两者都是 `+0.075`）。

**理由**：5.8 年 × 7 指数的样本量下，任何权重搜索都会把噪声拟合进参数。三档固定值让结论对权重不敏感，才具备可迁移性。

**替代方案**：用逻辑回归/机器学习拟合权重。否决理由——样本不足，且与项目"规则可解释、可对照通达信"的定位冲突。

### D5. 训练/验证分段预注册，且验证段只报不改

- 训练段（用于确认参数与相关性门槛是否成立）：2020-11-01 ~ 2023-12-31。
- 验证段（只用于报告准确率，不得据其调参）：2024-01-01 ~ 2026-10-29。
- 跨段合并样本只用于描述稳定性，不作为采纳依据。

若某候选在验证段样本不足（单方向合并样本 < 20），结论降级为"观察"，不判"采纳"。

### D6. 主口径不变，另加诊断指标

评价仍用现有"后续出现均线反转"作为主胜率口径，保证与历史信号可比；研究额外输出确认后 20 日最大有利偏移（MFE）、最大不利偏移（MAE）与 20 日收益中位数，仅作诊断，不进入胜率分母。

### D7. 相关性与替换式检验并存

相关性门槛预注册为：与任一现有维度的 Spearman `|ρ| ≥ 0.60` 视为重复维度。但允许一条**替换路径**：若新因子与某一维高相关，却在该维度单独作为替代时（用新因子替换该维、其余五维不变）验证段表现更好，则记为"该维的候选替代"，走与叠加路径相同的样本量与小样本约束。

**理由**：宽度与新高新低家数天然高相关，若只允许"叠加"，会误杀真正有信息量的替代关系。

### D8. 调研结论落成三态表，报告与 JSON 双产物

`data/research/external-signal-survey.json` 存结构化结果（证据表 + 候选池 + 检验数字 + 运行参数 + 数据版本），同目录一份 Markdown 报告供人阅读，结论列固定为 `采纳 / 观察 / 放弃`。

## Risks / Trade-offs

- **检验功效不足** → 5.8 年样本下，单指数单方向事件数可能只有个位数。缓解：以跨指数合并 + Wilson 区间为主口径，明确标注"本结论只回答是否值得进一步验证，不回答准确率提升多少"。
- **第三方数据事后修订** → 破净率、新高新低由第三方按当日全市场计算，可能随之后数据调整。缓解：manifest 记录抓取时间戳，隔期二次抓取比对同一历史日期取值；不一致则降级为 `P1` 并在报告中注明。
- **两融深交所接口为逐日粒度** → 需逐日回补，请求量大且易限流。缓解：先拉近 3 年，覆盖不足则整体降为 `P1`；失败不阻塞其他指标。
- **涨停家数历史短且不含退市标的** → 无法覆盖 2020 年以前。缓解：直接定级 `P1`，仅作辅助证据；若用于研究，只在有数据区间内报告，并单独标注区间。
- **相关门槛可能误杀** → 缓解见 D7 的替换路径。
- **预注册门槛被事后放宽** → 缓解：门槛写入 JSON 的 `preregistered` 字段，报告必须回显该字段；任何调整必须在报告中单独列出并说明原因，视为新的一轮检验。

## Migration Plan

无生产迁移。研究产物为新增目录（`data/raw/external/`、`data/research/external-signal-survey.json`）。回滚方式：删除上述产物与新增脚本即可，生产信号文件不受影响。验收时以"运行调研流程前后 `data/index-signals.json` 逐字节一致"作为隔离性证据。

## Open Questions

- 实际运行环境使用哪个 Python 解释器（本机默认解释器无 `akshare`）——不影响设计与任务拆分，实施时确认即可。
- 调研结果是否需要在页面上以"研究面板"形式展示——属于后续独立需求，不影响本变更。
