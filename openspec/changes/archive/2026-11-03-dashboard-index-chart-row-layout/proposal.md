# Proposal

## Why

【指标总览】当前 7 张指数图表按数据源顺序以桌面两列网格排列，上证指数与深证成指同行、末行只有中证1000 一张孤卡，用户指定的"大盘置顶独占一行、风格相近指数同行成对"的阅读顺序无法体现。按用户要求的 1+2+2+2 四行布局重排，可让大盘走势打头、配对指数左右对照，减少末行孤卡的浪费。

## What Changes

- 【指标总览】指数图表主区桌面布局从"每行两张、第 7 张横跨整行"改为用户指定的固定四行：
  - 第一行：上证指数独占一整行
  - 第二行：科创50 + 创业板指
  - 第三行：深证成指 + 沪深300
  - 第四行：中证500 + 中证1000
- 7 张图卡的渲染顺序按上述分组重排；每张图卡自身内容（标题、时间范围、信号标记、数据口径）不变。
- 仅前端展示层改动：不涉及信号计算、数据源、快照接口，任何指数信号数据不受影响。
- 窄屏（移动端）保持单列堆叠，按同一分组顺序依次排列。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `live-data-ui`: 修改"指标总览指数图表主区"需求——桌面布局从每行两张的通用网格改为固定的四行分组布局（1+2+2+2），并将"第 7 张独占末行"的场景替换为新分组场景。

## Impact

- `signal-hub-web/src/pages/Dashboard.tsx`：图表主区网格容器与 7 张 `IndexSignalChartCard` 的排序/跨列逻辑
- `signal-hub-web/tests/`：如现有测试断言两列布局或卡片顺序，需同步更新断言
- 不影响 `server/`、`pipeline/`、`data/` 的任何数据与信号计算
