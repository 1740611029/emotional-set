## 1. 当前生产算法（唯一生效口径）

**算法版本**：`sector-donchian20-ma60-v3.0-ths-source`（2026-11-14 起）
**数据源**：同花顺行业指数日线，**90 个细分行业**，不复权，缓存 `data/raw/sectors-ths-industry/{881xxx}.csv`
**核心代码**：`pipeline/confirmed_sector_trends.py`（版本号/强度/滞后降级）+ `pipeline/research_algorithms.py::sector_state`（四态判据本体，`Donchian20_MA60` 方法）
**产物**：`data/sector-trends.json`（as_of 2026-11-13 时版本已为 v3.0）

### 1.1 四态判据（两条判据组合，有效样本要求 60 个交易日收盘）

- 短判据：收盘价 > 唐奇安 20 日通道中轨 = (20 日最高 + 20 日最低) / 2
- 长判据：收盘价 > MA60（60 日均线）

| 状态 | 码 | 条件 | 语义 |
| --- | --- | --- | --- |
| 多头 | `bull` | 收盘 > 中轨 且 > MA60 | 两者皆上 |
| 退潮 | `warn` | 收盘 ≤ 中轨 且 > MA60 | 破中轨仍在年线上 |
| 空头 | `bear` | 收盘 ≤ 中轨 且 ≤ MA60 | 两者皆下 |
| 反转 | `rise` | 收盘 > 中轨 且 ≤ MA60 | 上穿中轨但年线下 |

不足 60 日样本 → `null`（不归类，不补造）。每个板块用**自身日线独立判定**，单层无父子关系。

### 1.2 有向强度（-50 ~ +50，四态统一公式，不按多空取反）

```
strength = (区间位置分 + MA60 偏离分) / 2 − 50
区间位置分 range_position = (close − LL20) / (HH20 − LL20) × 100   （0=区间最低，100=区间最高）
MA60 偏离分 ma_score = 50 + 50 × tanh((close/MA60 − 1) / 10%)
```

- 0 为中性，正偏强、负偏弱；例：两项均值 80 → 强度 +30；两项均值 20 → 强度 −30。
- 通道宽度为 0 → 强度固定 0、`strength_basis=neutral`、标记 `data_anomaly`（判定保留）。
- 无有效状态 → 强度、构成分、口径均为空。

### 1.3 辅助规则

- **持续天数**：连续处于同一状态的交易日数，状态变化即重置 1。
- **滞后降级**（保守规则，换源前沿用，只作用于最新条目，不进历史序列）：尾日早于产物 `as_of` → 标 `data_lag` 仍展示；滞后 > 30 自然日 → 清空 state/strength/strength_parts/strength_basis/days，宁缺勿错。
- **方向胜率评估**（`evaluation`）：研究段（2020-10-30~2024-12-31）/ 验证段（2025-01-02 起）× 前瞻 10/20 日 × 四态分组；每格 = 胜率 + 已判定样本 + Wilson 95% 区间 + 小样本标记；方向期望 bull/rise 涨、warn/bear 跌，未决不计分母。`research_status=post_hoc_exploratory_not_independent`：验证段是事后观察、不构成独立验证，整体为**描述性分类，不代表交易收益**。

## 3. 测试过且不通过（淘汰，勿重复测）

### 3.1 数据源候选（2026-11-14 探测，9 条通道实测）

背景：东财 push2 系 IP 限流，需找可与 31 行业一一对应的免费日线。证据：`data/research/source-eval/probe-sectors-conclusion-20261114.md`（明细 JSON 同目录）。

| 候选 | 结果 | 原因 |
| --- | --- | --- |
| 申万一级日线 × 东财 push2his | ❌ | IP 限流未恢复，东财域名同属 push2 系 |
| 申万一级日线 × 新浪 KLineData | ❌ | 返回 null，新浪无申万代码 |
| 申万一级日线 × 腾讯 ifzq | ❌ | 代码存在但 day 为空 |
| 申万一级日线 × 百度股市通 | ❌ | 403 反爬 |

| 申万一级日线 × 乐咕乐股 | ❌ | 无日线接口（仅清单+估值） |
| 申万一级日线 × 申万宏源官网 | ❌ | SPA 无下载通道 |
| 申万一级日线 × akshare 内置 | ❌ | 无日线接口（仅清单/分类） |

## 4. 候选算法池与留痕缺口（重要）

`pipeline/research_algorithms.py::SECTOR_METHODS` 保留了 **10 个候选四态判据方法**：

`MA10_30`、`MA20_60`、`MACD`、`ROC20_60`、`Regression20_60`、`DMI14_MA60`、`Aroon25_MA60`、`Supertrend10_3_MA60`、`RelativeMomentum20_60`、`CompositeVote`（另含生产方法 `Donchian20_MA60`）。

- 回测入口：`pipeline/run_algorithm_research.py`（只读，输出 `data/research/first-round.json` + `sector-second-review.json`，含 overall/by_state/by_sector/by_year 四维汇总）。
- **留痕缺口（如实声明）**：这两个回测结果文件从未提交 git，本机也已不存在，**选型期各方法的具体胜率数字不可追溯**。已知事实只有：生产最终采用 `Donchian20_MA60`，其余 9 个方法代码保留为研究用途。
- 因此：**把"其余 9 个方法测过且差"当作未证实假设**。若用户要求重新选型，用 `run_algorithm_research.py` 重跑一遍（注意它当前读的是旧申万缓存路径 `data/raw/sectors/{level}`，重跑前需先适配新源路径），结果落盘后必须 git 提交并在登记表登记。

## 5. 新算法测试规范（后续推理/测试必须遵守）

1. **调参与验证分离**（AGENTS #7）：训练段 2020-10-30~2024-12-31 选参，验证段 2025-01-01 起只作报告；隔离期 20 个交易日。
2. **数据源切换评估先冻结门槛**：测试开始前把门槛落盘 `data/research/source-eval/thresholds.json`，测完不得下调（沿用 stable-market-data-source-migration 的做法）。
3. **准确率必须带样本量**（AGENTS #8）：报告任何胜率同时给已判定样本数、统计区间、Wilson 95% 区间；样本少如实披露，不得省略或补造。
4. **禁止未来函数**（AGENTS #1）：全部 rolling 历史窗口；ZigZag/通道类"事后确认"结构必须保证信号日不早于确认日。
5. **对照基准**：新算法必须与现行 Donchian20_MA60 在同区间、同口径逐日对照（板块数、行业日数、四态一致率、翻转类型分布），结论写登记表。
6. **回写本文档**：无论通过/不通过/搁置，登记表加一行；不通过的写明淘汰原因与数据，防止重复测试。
7. **研究脚本只写 `data/research/`**，不触碰生产 JSON 与 `data/raw/`。
